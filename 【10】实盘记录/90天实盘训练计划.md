# 90 天实盘训练计划

> **目标**：用 90 天低风险实盘验证投资体系 V5.0 的可执行性，积累同口径样本，完成第一次集中规则修改。  
> **考核重点**：不是收益率，而是系统内交易占比、规则执行率、日志完整性和回撤控制。  
> **关联文档**：[[投资体系_V5.0]] · [[买入卡模板]] · [[复盘卡模板]] · [[策略评估筛选框架]] · [[季度系统健康报告模板]]

---

## 总览

```text
第 1—30 天   建立基础设施 · 风险 ≤ 0.3% · ≥ 10 笔完整记录
第 31—60 天  验证三类策略 · 统计每类表现 · 风险 ≤ 0.5%
第 61—90 天  积累同口径样本 · 第一次规则修改 · 形成 V5.1
```

| 阶段 | 天数 | 核心任务 | 风险上限 | 最低样本 |
|---|---|---:|---:|---:|
| 第一阶段 | 1—30 | 基础设施 + 纪律训练 | 0.3% | 10 笔 |
| 第二阶段 | 31—60 | 策略分类验证 | 0.5% | 15 笔 |
| 第三阶段 | 61—90 | 样本积累 + 规则迭代 | 0.5%（达标后可 0.7%） | 30 笔（累计） |

---

## 第一阶段：第 1—30 天 · 基础设施期

### 目标

建立可重复的交易记录习惯，证明能在真实资金下执行规则，**不考核收益**。

### 每日动作

- [ ] 盘前完成交易计划（使用 [[买入卡模板]]）
- [ ] 盘中只执行计划内交易
- [ ] 盘后更新 [[持仓卡模板]] 和日复盘
- [ ] 每笔平仓后 24 小时内完成 [[复盘卡模板]]

### 检查清单

**Week 1（第 1—7 天）**

- [ ] Obsidian 目录结构就绪，`交易日志/` 有至少 1 笔记录
- [ ] 买入卡、持仓卡、复盘卡模板已熟悉
- [ ] 完成第一笔系统内交易（风险 ≤ 0.3%）
- [ ] 建立股票池 A/B/C 三级分类

**Week 2（第 8—14 天）**

- [ ] 累计 ≥ 3 笔完整交易记录
- [ ] 每笔记录含 MFE/MAE
- [ ] 完成第一次周复盘（[[周报模板]]）
- [ ] 无系统外交易

**Week 3（第 15—21 天）**

- [ ] 累计 ≥ 6 笔完整记录
- [ ] 规则执行率自评 ≥ 80%
- [ ] 识别个人 Top 3 行为偏差
- [ ] 市场 A/B/C/D 判断有书面记录

**Week 4（第 22—30 天）**

- [ ] 累计 ≥ 10 笔完整记录
- [ ] 完成第一份月报（[[月报模板]]）
- [ ] 所有新交易风险 ≤ 0.3%
- [ ] 无因违规造成的 > 1R 损失

### 达标标准

| 指标 | 阈值 | 实际 |
|---|---:|---:|
| 完整交易记录 | ≥ 10 笔 | |
| 单笔风险 | ≤ 0.3% | |
| 规则执行率 | ≥ 80% | |
| 日志完整率 | 100% | |
| 系统内交易占比 | ≥ 85% | |

**未达标处理**：延长第一阶段 2 周，不进入第二阶段。

## 第二阶段：第 31—60 天 · 策略验证期

### 目标

区分三类核心策略，统计每类胜率、R 倍数和违规率，删除无法清晰定义的交易模式。

### 三类策略定义

| 策略 | 代码 | 典型场景 | 入场信号 |
|---|---|---|---|
| **创新药价值重估** | STR-A | 迪哲医药类 | 基本面确认 + 日线趋势 + 硬催化 |
| **事件驱动第二波** | STR-B | 地缘/商品/政策事件后 | 板块联动 + 二次确认 + 20 日突破 |
| **趋势回调买入** | STR-C | 产业趋势中的回调 | 55 日趋势向上 + 回调至支撑 + 重新突破 |

> 每笔交易必须在买入卡中标注策略代码，便于后续统计。

### 每周动作

- [ ] 按策略分类汇总本周 R
- [ ] 检查每类策略是否有清晰、可重复的入场/退出规则
- [ ] 删除或暂停无法定义规则的"感觉交易"
- [ ] 更新 [[周报模板]]

### 检查清单

**Week 5—6（第 31—44 天）**

- [ ] 三类策略各有 ≥ 2 笔标注记录
- [ ] 累计交易 ≥ 15 笔
- [ ] 每类策略有独立的胜率/R 初算
- [ ] 风险上限仍 ≤ 0.5%

**Week 7—8（第 45—60 天）**

- [ ] 累计交易 ≥ 20 笔
- [ ] 识别表现最差策略（期望值 < 0 或执行率 < 70%）
- [ ] 完成第二份月报
- [ ] 初步判断哪类策略最适合个人能力圈

### 达标标准

| 指标 | 阈值 | 实际 |
|---|---:|---:|
| 累计完整记录 | ≥ 20 笔 | |
| 三类策略各有样本 | ≥ 2 笔/类 | |
| 单笔风险 | ≤ 0.5% | |
| 规则执行率 | ≥ 85% | |
| 无法定义规则的交易 | 0 笔 | |

**未达标处理**：暂停新增交易 1 周，集中补齐日志和策略定义。

## 第三阶段：第 61—90 天 · 样本积累与规则迭代期

### 目标

积累至少 30 笔同口径样本，完成**第一次集中规则修改**（不逐笔修改），形成投资体系 V5.1。

### 核心原则

- 规则修改必须基于 ≥ 30 笔同口径样本，不因单笔盈亏调整
- 每季度最多一次正式版本升级
- 只有期望值 > 0 且执行率 ≥ 90% 的策略，才可提升风险至 0.7%

### 每周动作

- [ ] 继续按策略分类记录
- [ ] 追踪累计 Profit Factor 和期望值
- [ ] 标记待观察问题（不在样本不足时修改规则）
- [ ] 周末选一笔交易做完整深度复盘

### 检查清单

**Week 9—10（第 61—74 天）**

- [ ] 累计 ≥ 25 笔同口径样本
- [ ] 各策略期望值初算完成
- [ ] 规则执行率 ≥ 88%
- [ ] 最大回撤在预设区间内（峰值 < 6%）

**Week 11—12（第 75—90 天）**

- [ ] 累计 ≥ 30 笔同口径样本
- [ ] 完成 [[季度系统健康报告模板]]
- [ ] 召开"个人投资委员会"：审查全部样本
- [ ] 输出 V5.1 规则修改清单（≤ 3 条）
- [ ] 确定下季度保留的 2—3 个核心策略

## 训练期禁止事项

1. 不因单笔大盈利提高风险预算
2. 不因连续亏损放弃止损规则
3. 不在样本 < 30 笔时修改核心参数
4. 不将系统外盈利视为系统有效
5. 不在情绪高峰（大盈/大亏后）做规则变更
6. 不使用 > 1% 单笔风险（训练期绝对上限）
