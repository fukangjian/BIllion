# 统计目录说明

本目录用于存放阶段性统计汇总和可视化数据导出。

## 用途

- 季度/年度 R 分布汇总
- 各策略累计期望值与 Profit Factor 追踪表
- 资金曲线数据（CSV/Markdown 表格）
- 月度/季度系统健康报告归档副本
- 90 天训练期阶段性验收记录

## 建议文件命名

```
YYYY-QN_季度统计.md
YYYY_年度统计.md
90天训练_阶段验收.md
策略表现_累计追踪.md
```

## 关联模板

- [[月报模板]]
- [[季度系统健康报告模板]]
- [[策略评估筛选框架]]
- [[90天实盘训练计划]]

## 数据来源

每笔交易的 R 倍数、MFE/MAE 来自 `交易日志/` 中的 [[复盘卡模板]] 记录。  
周度汇总来自 `每周复盘/`，月度汇总来自 `每月复盘/`。

> 量化工具上线后，Python 脚本可自动从此目录读取 SQLite 导出数据并生成图表。
