# 基于《周期》的个人投资体系.md

> 目标：把《周期》的思想转化为适合A股个人投资者的操盘系统。该体系偏“职业投资者训练版”，核心是用周期位置决定仓位，用赔率决定动作，用复盘修正认知。

## 1. 总纲

我的投资体系不是预测体系，而是“周期—赔率—仓位—执行—复盘”体系。

核心公式：

```text
投资动作 = 周期位置 × 预期差 × 资金确认 × 风险收益比 × 仓位纪律
```

只有当多个变量共振时，才允许提高仓位；任何单一利好都不能成为重仓理由。

## 2. 我的能力圈

### 2.1 主能力圈

1. **A股主题投资**：创新药、AI算力、半导体、商业航天、脑机接口、油气等。
2. **产业链扩散逻辑**：从龙头到上游材料、设备、服务、应用端。
3. **事件驱动交易**：政策、订单、BD授权、临床数据、业绩拐点、地缘冲突。
4. **边际变化捕捉**：低位放量、资金试盘、板块轮动、预期差修复。
5. **软件/嵌入式技术背景辅助理解**：可用于AI、半导体、工业控制、物联网、边缘计算等技术产业分析。

### 2.2 暂不作为主战场

1. 高频交易和纯量化日内博弈。
2. 无基本面支撑的纯打板赌博。
3. 高杠杆期权卖方策略。
4. 借贷炒股和融资满仓。
5. 自己无法解释产业逻辑的陌生题材。

## 3. 周期四层评分模型

每只股票买入前必须给四个周期打分，每项0—5分，总分20分。

| 周期层 | 观察指标 | 0分 | 5分 |
|---|---|---|---|
| 宏观/流动性周期 | 大盘成交额、风险偏好、政策、利率、指数趋势 | 缩量下跌、风险偏好低 | 放量修复、政策友好 |
| 行业周期 | 景气度、政策、供需、渗透率、估值位置 | 行业下行且无拐点 | 低位改善且催化明确 |
| 公司周期 | 业绩、产品、订单、管线、公告、现金流 | 逻辑恶化 | 边际变化强且可验证 |
| 市场/情绪周期 | 板块涨停家数、资金承接、换手、分时、舆论 | 一日游或高位退潮 | 板块扩散、承接强 |

### 评分对应动作

| 总分 | 动作 |
|---|---|
| 0—7分 | 不买，只观察 |
| 8—11分 | 小仓试错，仓位≤10% |
| 12—15分 | 标准参与，仓位10%—30% |
| 16—18分 | 强共振，仓位30%—50% |
| 19—20分 | 极罕见机会，仍不得无脑满仓，必须设置退出规则 |

## 4. 仓位系统

### 4.1 单票仓位上限

| 类型 | 单票上限 |
|---|---:|
| 观察试错 | 5%—10% |
| 右侧确认 | 10%—20% |
| 强逻辑核心票 | 20%—35% |
| 极强周期共振 | 35%—50% |
| 单票满仓 | 原则上禁止 |

### 4.2 总仓位规则

| 市场状态 | 总仓位 |
|---|---:|
| 大盘缩量下跌、无主线 | 0%—30% |
| 有局部主线，但分歧大 | 30%—50% |
| 主线清晰，板块扩散 | 50%—80% |
| 全市场赚钱效应强 | 80%以内，仍保留现金 |
| 高位一致亢奋 | 主动降至30%—50% |

### 4.3 风险预算

- 单笔交易最大亏损控制在总本金的1%—2%。
- 连续亏损3笔，暂停交易，强制复盘。
- 单周回撤超过5%，降低总仓位一半。
- 单月回撤超过10%，停止进攻，只允许小仓验证。
- 禁止借贷炒股，禁止用融资或期权卖方放大风险。

## 5. 买入系统

### 5.1 买入前必须满足的基础条件

1. 有明确的周期逻辑：不是随便看到涨就买。
2. 有明确的边际变化：公告、业绩、订单、政策、价格、临床数据、BD、供需改善等。
3. 有明确的预期差：市场还没有完全计价，或刚开始重估。
4. 有资金确认：放量、承接、板块联动至少满足其一。
5. 有风险边界：知道什么情况说明自己错了。
6. 有卖出计划：买入前先写卖出条件。

### 5.2 三类买点

#### A. 左侧研究买点

适用：公司基本面在低位改善，但市场尚未充分反应。

条件：

- 股价长期低迷；
- 公司或行业出现可验证边际改善；
- 市场关注度低；
- 估值未明显修复；
- 下跌空间可控。

仓位：5%—15%。

#### B. 右侧确认买点

适用：放量突破、板块扩散、事件催化落地。

条件：

- 个股放量突破关键平台；
- 板块涨幅排名靠前；
- 板块涨停家数增加；
- 分时承接强，跌破均价线能拉回；
- 次日没有明显高开低走。

仓位：10%—30%。

#### C. 回调承接买点

适用：强逻辑个股第一次分歧，但逻辑未破。

条件：

- 核心逻辑仍成立；
- 缩量回调；
- 板块未退潮；
- 关键均线或平台有承接；
- 大盘未系统性恶化。

仓位：按原计划补，不因情绪恐慌乱加。

## 6. 卖出系统

### 6.1 逻辑卖出

出现以下情况直接降低仓位或退出：

1. 买入逻辑被证伪。
2. 公告不及预期。
3. 临床、订单、业绩、政策发生实质利空。
4. 行业周期从改善转为恶化。
5. 原本的预期差被市场充分计价。

### 6.2 技术/资金卖出

1. 放量滞涨。
2. 高开低走且无法收回均价线。
3. 跌破关键平台且次日不能修复。
4. 板块涨停家数明显减少。
5. 龙头杀跌，跟风股补跌。
6. 大盘风险偏好快速下降。

### 6.3 盈利卖出

- 浮盈10%：检查逻辑是否强化，不机械卖出。
- 浮盈20%：至少卖出20%—30%仓位锁定利润，除非板块刚启动且承接极强。
- 浮盈30%以上：改用移动止盈，不再允许盈利大幅回吐。
- 连续加速上涨：越涨越减，而不是越涨越贪。

### 6.4 止损规则

- 左侧试错：跌破逻辑位或亏损5%—8%止损。
- 右侧突破：突破失败、跌回平台止损。
- 事件驱动：利好兑现后不涨或高开低走，快速退出。
- 任何交易亏损达到预设金额，不补仓摊低，先复盘。

## 7. 创新药专题交易模板

### 7.1 研究维度

| 维度 | 关键问题 |
|---|---|
| 疾病领域 | 是否大适应症？患者数、未满足需求如何？ |
| 靶点/机制 | 是否有差异化？是否同质化严重？ |
| 临床数据 | ORR、PFS、OS、安全性是否有竞争力？ |
| 注册路径 | 是否进入关键III期？是否有突破性疗法认定？ |
| 商业化 | 是否进医保？销售放量是否可验证？ |
| 海外BD | 是否有MNC合作可能？交易结构如何？ |
| 财务 | 现金能烧多久？是否要再融资？ |
| 估值 | 市场是否已经按成功定价？ |

### 7.2 买入优先级

1. 核心产品已获批 + 销售放量 + 估值仍低。
2. 关键III期数据优秀 + 海外BD预期强。
3. 医保进入后销售曲线快速验证。
4. 大药企授权首付款高，现金流改善。
5. 板块处于低位启动，资金扩散明显。

### 7.3 风险排除项

1. 只有小作文，没有公告或数据。
2. 临床数据样本小且不可验证。
3. 现金紧张，频繁融资。
4. 同靶点竞争拥挤，差异化不足。
5. 股价已经连续大涨，估值透支。
6. 板块只有一只独涨，没有扩散。

## 10. 我的最终投资信条

1. 我不靠预测生存，靠赔率、纪律和复盘生存。
2. 我不追求每天赚钱，追求长期复利。
3. 我不把单次盈利当能力，只把长期样本当能力。
4. 我不在情绪高位满仓，也不在极端低位彻底放弃研究。
5. 我只在周期、产业、公司、资金四者共振时重仓。
6. 我允许错，但不允许大错；允许亏，但不允许失控。
7. 我把市场当老师，把复盘当训练，把本金当生命线。
