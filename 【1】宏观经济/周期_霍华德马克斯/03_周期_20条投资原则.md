# 《周期》提炼的20条投资原则.md

## 20条投资原则

1. **周期永远存在**：不要相信“这次不一样”，只要人性还在，极端就会反复出现。
2. **不要预测精确拐点**：投资的重点不是猜顶和底，而是判断当前位置偏贵还是偏便宜。
3. **用赔率替代确定性**：好投资不是必然赚钱，而是风险收益比足够好。
4. **低位研究机会，高位研究风险**：越没人要，越要研究；越人人看好，越要警惕。
5. **价格是周期的一部分**：好公司高价买也可能是差投资，差公司低价买也未必安全。
6. **预期差决定超额收益**：市场不知道、低估、怀疑的变化，才可能带来超额回报。
7. **边际变化重于静态好坏**：股价常反映变化速度，而不是公司“绝对好坏”。
8. **情绪是反向指标，但不是立即反转信号**：极度乐观说明风险高，不等于明天就跌；极度悲观说明机会近，不等于马上涨。
9. **资金宽松推升估值，资金收紧压缩估值**：成长股和主题股尤其依赖流动性与风险偏好。
10. **信贷/融资环境是风险温度计**：钱越容易拿，投资人越容易低估风险；钱越难拿，优质资产越可能被错杀。
11. **盈利周期要看拐点而非单期利润**：收入增速、费用率、毛利率、盈亏平衡趋势比单个季度盈亏更重要。
12. **行业周期要看供需再平衡**：产能、库存、价格、政策、技术替代共同决定景气位置。
13. **成功会制造失败的种子**：连续赚钱后最容易仓位过大、标准降低、忽视风险。
14. **亏损会制造机会的种子**：连续下跌后若基本面未死，低估和低预期可能带来高赔率。
15. **防守也是投资能力**：长期复利首先来自活下来，其次才是赚大钱。
16. **仓位必须服从周期位置**：低位改善可逐步进攻，高位拥挤必须降低暴露。
17. **现金是看跌期权**：市场极端悲观时，现金能买到他人被迫卖出的筹码。
18. **拒绝被短期市场奖励误导**：一次赚钱不能证明方法正确，一次亏损也不能证明逻辑错误。
19. **买入前写下证伪条件**：没有证伪条件的交易，本质是情绪赌博。
20. **复盘要修正体系，不是安慰自己**：每笔交易都要归因到周期、逻辑、价格、仓位、执行五个层面。

## 适合A股的执行化翻译

| 原则 | A股执行动作 |
|---|---|
| 周期位置 | 每周给宏观、板块、个股、情绪打分 |
| 赔率 | 买入前计算上涨空间/下跌空间，至少要求2:1以上 |
| 预期差 | 优先找“市场还没完全相信”的变化 |
| 仓位纪律 | 低证据小仓，强共振中仓，高拥挤减仓 |
| 资金确认 | 看板块联动、成交量、涨停家数、分时承接 |
| 风险控制 | 单笔风险预算固定，严禁借贷加仓 |
