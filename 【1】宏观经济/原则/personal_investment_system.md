# 个人投资体系补充：把《原则》落地为职业投资者操作系统

> 目标：面向 5 年内成为职业投资者的路线，建立“研究—交易—风控—复盘—迭代”闭环。  
> 适用市场：A 股为主，兼顾港股/美股/ETF/现金管理。  
> 说明：以下是体系框架，不是具体买卖建议。

---

## 1. 总纲：先活下来，再进化，再复利

个人投资者最容易犯的错误是把目标设成“快速赚钱”。职业投资者的真实顺序应该是：

```text
生存能力 → 稳定能力 → 放大能力 → 复利能力
```

对应原则：

1. **先控制破产风险**：不借钱投机，不满仓赌单一方向。
2. **先做可重复交易**：一次暴利不等于体系有效。
3. **先建立样本库**：至少用 100 笔交易检验自己的风格。
4. **先守住本金和心态**：大回撤会摧毁认知和执行力。

---

## 2. 投资系统总架构

```text
战略层：长期目标、收益目标、回撤约束、能力圈
研究层：宏观、政策、产业、公司、估值、催化
交易层：买点、卖点、仓位、时间窗口、执行纪律
风控层：单票上限、板块上限、总仓位、止损、现金
复盘层：交易日志、错误库、原则库、月度归因
迭代层：规则升级、模型优化、能力扩展
```

你本身具备软件架构背景，最适合用系统工程方式做投资：模块分层、接口清晰、日志完整、版本迭代。

## 3. 投资目标设定

### 3.1 第一阶段：0-12个月

目标不是赚大钱，而是建立系统。

| 指标 | 目标 |
|---|---|
| 最大回撤 | 控制在 10%-15% 以内 |
| 单票亏损 | 不超过总资金 2%-3% |
| 交易记录 | 完成不少于 100 笔有效样本 |
| 行业研究 | 形成 5 个核心产业链框架 |
| 原则库 | 沉淀不少于 50 条规则 |

### 3.2 第二阶段：1-3年

目标是形成稳定风格。

- 明确自己擅长：事件驱动、产业趋势、价值成长、周期波段中的哪一类。
- 建立核心观察池 50-100 只。
- 每年只做 5-10 个真正高质量大机会。
- 避免每天都想交易。

### 3.3 第三阶段：3-5年

目标是职业化。

- 有稳定收益曲线。
- 有清晰回撤控制能力。
- 有可解释的收益来源。
- 有穿越不同市场阶段的适应能力。

## 4. 资产与仓位结构

以 100 万本金为例，可采用保守型职业化训练结构：

| 模块 | 比例 | 用途 |
|---|---:|---|
| 核心趋势/价值仓 | 40%-50% | 产业趋势、基本面改善、确定性较高标的 |
| 事件驱动仓 | 15%-25% | 政策、订单、BD、业绩、审批等催化 |
| 试错学习仓 | 5%-10% | 新行业、新策略、小仓验证 |
| ETF/防守仓 | 10%-20% | 宽基、红利、债券ETF、现金增强 |
| 现金 | 10%-20% | 等待机会、应对回撤、保持心理稳定 |

### 单票仓位建议

| 标的类型 | 单票仓位上限 |
|---|---:|
| 观察试错 | 1%-3% |
| 初步确认 | 5% |
| 高确定性事件 | 8%-10% |
| 核心中线 | 10%-15% |
| 单票绝对上限 | 15%，极少数情况才允许 |

核心思想：**仓位不是表达信心，仓位是表达确定性、赔率和风险承受能力的综合结果。**

## 5. 研究体系

### 5.1 四层研究法

```text
宏观环境 → 产业逻辑 → 公司质量 → 交易结构
```

#### 宏观环境

- 流动性是否宽松？
- 指数处于风险偏好扩张还是收缩？
- 政策方向是否支持该板块？

#### 产业逻辑

- 行业处于导入期、成长期、成熟期还是衰退期？
- 需求是否真实扩张？
- 供给是否受限？
- 价格、订单、库存、政策是否形成共振？

#### 公司质量

- 公司在产业链中的位置。
- 产品差异化。
- 财务质量。
- 管理层能力。
- 商业模式和竞争壁垒。

#### 交易结构

- 股价位置。
- 成交额和换手。
- 板块强度。
- 市场情绪。
- 是否存在拥挤交易。

## 6. A 股创新药投资模块

根据迪哲医药案例，创新药投资应建立独立模块。

### 6.1 核心变量

| 变量 | 解释 |
|---|---|
| 临床价值 | 是否解决未满足临床需求，数据是否有差异化 |
| 审评节点 | CDE/FDA 受理、优先审评、突破性疗法、上市批准 |
| 医保准入 | 是否能改善患者可及性和销售放量 |
| 商业化能力 | 销售团队、医院覆盖、适应症大小 |
| BD潜力 | 是否具备 license-out 或跨国药企合作价值 |
| 现金流 | 研发投入大，现金储备和融资能力关键 |
| 估值弹性 | 市场是否只按国内销售估值，还是给予全球权益估值 |

### 6.2 买入前检查

一只创新药股票，至少满足 6 条才可中等仓位：

- 有明确核心产品，而不是散乱管线。
- 临床数据具有差异化优势。
- 适应症有未满足需求。
- 有真实监管节点推进。
- 有医保、销售或 BD 的兑现路径。
- 现金流能支撑后续研发。
- 股价尚未充分透支预期。
- 板块情绪和市场环境不处于明显退潮。

### 6.3 卖出条件

- 核心临床数据低于预期。
- 审批进度明显延迟且无合理解释。
- 医保价格或销售放量不及预期。
- BD 预期落空，且估值已提前反映。
- 连续加速上涨后成交结构恶化。
- 板块退潮且个股不能独立承接。

## 7. 交易体系

### 7.1 买入流程

```text
进入观察池 → 写研究卡片 → 等待触发 → 小仓试错 → 承接确认 → 加仓 → 跟踪验证 → 止盈/止损
```

### 7.2 三类买点

| 买点 | 特征 | 风险 |
|---|---|---|
| 左侧低位潜伏 | 估值低、催化未兑现 | 等待时间长，可能继续跌 |
| 右侧突破确认 | 趋势和资金确认 | 成本较高 |
| 事件后分歧承接 | 利好兑现后换手充分 | 容易买到情绪退潮 |

### 7.3 禁止买入清单

- 不知道为什么涨。
- 只因为别人赚钱而买。
- 买入前没有止损条件。
- 高位连续加速但没有承接验证。
- 同板块已明显退潮。
- 重大利好后估值明显透支。
- 自己情绪亢奋，想“必须上车”。

---

## 8. 风控体系

### 8.1 回撤阈值

| 回撤 | 动作 |
|---|---|
| -5% | 降低交易频率，检查错误类型 |
| -10% | 总仓位降至 50% 以下，暂停追高交易 |
| -15% | 进入防守模式，只保留高确定性仓位 |
| -20% | 停止主动交易一周，进行系统复盘 |

### 8.2 单票风险

- 单票最大亏损控制在账户总资产 2%-3%。
- 事件驱动票不得无止损持有。
- 科创板/创业板 20cm 股票必须降低仓位系数。
- 未盈利创新药公司必须考虑融资、研发失败和估值波动风险。

### 8.3 板块风险

- 单一板块总仓位不超过 30%-40%。
- 同一题材多只股票不能伪装成分散投资。
- 板块龙头退潮时，后排股优先减仓。

每月底统计：

- 哪类交易赚钱最多？

- 盈亏比是多少？
- 最大回撤来自哪只股票？
- 是否有重复错误？
- 本月新增哪些原则？

## 10. 与量化交易的关系

你不需要“对抗量化”，而要避开量化最强的区域，并利用自己相对优势。

### 量化强项

- 高频交易。
- 微结构套利。
- 多因子排序。
- 统计回测。
- 执行速度。

### 个人投资者相对优势

- 能理解复杂产业逻辑。
- 能忍受中低频等待。
- 能在小资金规模下灵活切换。
- 能提前研究小众公司。
- 能做深度主观判断。

### 正确融合方式

- 用量化思维做纪律：仓位、回撤、胜率、盈亏比。
- 用主观研究做认知：产业、公司、催化、预期差。
- 不在日内高频上和机器竞争。
- 在中低频产业趋势和事件驱动上建立优势。

## 11. 个人原则库 V1.0

1. 不借钱炒股。
2. 不满仓赌单一方向。
3. 不因踏空而追高。
4. 不把短线失败改成长线。
5. 不买看不懂关键变量的公司。
6. 不相信没有证据的小作文。
7. 不忽视公司公告里的风险提示。
8. 不在情绪最亢奋时扩大仓位。
9. 不让单票亏损超过账户 3%。
10. 不让一次赚钱破坏仓位纪律。
11. 每笔交易必须写计划。
12. 每次亏损必须入库。
13. 每周必须更新观察池。
14. 每月必须做收益归因。
15. 每季度必须审视能力圈。
16. 只在事实、逻辑、资金、赔率共振时重仓。
17. 现金是机会，不是懦弱。
18. 错过机会不是风险，永久亏损才是风险。
19. 投资体系比单只牛股重要。
20. 职业投资者的本质是持续升级决策系统。

## 12. 下一步执行计划

### 第 1 周

- 建立交易日志模板。
- 建立观察池：创新药、AI算力、半导体、商业航天、周期资源各 10 只。
- 给每只股票写一页研究卡片。

### 第 1 个月

- 只用小仓位验证体系。
- 完成 20 次复盘记录。
- 找出自己最常犯的 3 类错误。

### 第 1 季度

- 固定 2-3 个主攻方向。
- 删除不适合自己的交易风格。
- 建立第一版仓位模型。

### 第 1 年

- 形成稳定的研究框架。
- 形成稳定的风控纪律。
- 形成可验证的收益归因。
- 判断自己是否具备继续扩大资金规模的资格。

## 13. 最终结论

你的个人投资体系应该不是“寻找下一只涨停股”，而是建立一台可持续运行的投资机器：

```text
事实输入 → 逻辑处理 → 概率评估 → 仓位表达 → 风险控制 → 结果反馈 → 原则升级
```

这台机器的目标不是每次都赢，而是让你在足够多的样本中：

- 大亏减少。
- 小亏可控。
- 小赚稳定。
- 大赚不被过早放弃。
- 每次错误都推动系统进化。

这才是从个人投资者走向职业投资者的可行路径。
