# 《原则》投资化研读资料包

本资料包包含 5 个 Markdown 文件：

1. `principles_mindmap.md`：思维导图，含 Mermaid mindmap。
2. `principles_reading_notes.md`：结构化读书笔记。
3. `principles_20_investment_rules.md`：20 条投资原则与检查表。
4. `dizal_case_study.md`：A 股真实案例验证，聚焦迪哲医药创新药与授权交易。
5. `personal_investment_system.md`：个人投资体系补充，覆盖研究、交易、风控、复盘和量化融合。

使用建议：

- 先读读书笔记，建立整体认知。
- 再读 20 条投资原则，把原则转成交易清单。
- 再读迪哲医药案例，理解原则如何验证真实 A 股事件。
- 最后用个人投资体系文件改造自己的日常交易流程。

说明：

- 内容基于《原则》的公开方法论与结构化研读，不复刻原书内容。
- 迪哲医药案例截至 2026-07-15，可作为创新药事件驱动研究模板。
- 所有投资相关内容仅用于研究框架建设，不构成投资建议。
