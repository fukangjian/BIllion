# 《竞争优势》A 股案例验证

> 说明：用户所写“迪泽医药”通常指 **迪哲医药（688192.SH）**。本文件以迪哲医药为主案例，并用宁德时代、美的集团、贵州茅台和通源石油作横向对照。案例用于验证战略框架，不构成证券推荐。

## 一、案例分析方法

每家公司按以下七个问题分析：

1. 真实细分市场与竞争范围是什么？
2. 客户价值主张是什么？
3. 优势属于低成本、差异化还是聚焦？
4. 优势落在哪些价值活动？
5. 活动之间是否形成系统协同？
6. 优势在财务或商业结果中是否得到验证？
7. 哪些因素可能使优势失效？

---

# 案例一：迪哲医药——创新药的差异化聚焦

## 1. 战略定位

迪哲医药不是依靠全品类覆盖或制造规模竞争，而是聚焦肿瘤等重大疾病中存在明确未满足需求的细分人群，通过原创小分子药物、临床证据和全球注册形成差异化。

其战略更接近：

```text
窄竞争范围 + 高临床价值差异化 = 差异化聚焦
```

## 2. 价值链拆解

```text
疾病机制与靶点选择
→ 分子设计与发现
→ 临床前验证
→ 临床试验设计和患者入组
→ 中美等监管沟通与注册
→ 商业化生产和质量体系
→ 医学事务、医生教育和患者识别
→ 医保、准入和商业推广
→ 上市后研究与适应症扩展
```

迪哲医药的优势重点不在低成本生产，而在前半段研发和中段临床注册。创新药的客户并非单一患者，还包括医生、医院、支付方和监管机构，因此“差异化”必须同时体现在疗效、安全性、适用人群、证据强度和可支付性上。

## 3. 舒沃替尼：差异化得到跨市场验证

舒沃替尼用于特定 EGFR 突变非小细胞肺癌人群。其在中国于 2023 年获附条件批准；美国 FDA 于 2025 年 7 月 2 日给予加速批准，用于既往接受过含铂化疗后进展的 EGFR 20 号外显子插入突变局部晚期或转移性非小细胞肺癌成人患者。

这项事实的重要性不只是“海外获批”题材，而是说明其价值链至少在以下环节获得验证：

- 分子具有可识别的临床差异化；
- 临床方案和数据质量达到监管要求；
- 全球注册和组织执行能力得到阶段性证明；
- 产品从研发资产转化为商业资产的概率提高。

## 4. 戈利昔替尼：第二个差异化支点

戈利昔替尼是一款高选择性 JAK1 抑制剂，于 2024 年 6 月在中国获附条件批准，用于复发或难治性外周 T 细胞淋巴瘤。第二款产品获批意味着公司不再完全依赖单一分子，也初步证明研发平台存在一定重复性。

但“两个产品”仍不足以证明完整平台型护城河。投资者需要继续跟踪：

- 后续适应症和临床成功率；
- 海外注册进展；
- 商业化销售爬坡；
- 医保和价格变化；
- 同类竞品上市速度；
- 研发费用与现金储备。

## 5. 迪哲医药的优势与短板

| 维度 | 判断 | 证据/解释 |
|---|---|---|
| 竞争范围 | 聚焦 | 聚焦特定肿瘤和分子亚型 |
| 主要优势 | 差异化 | 疗效、安全性、特定人群和全球临床证据 |
| 价值链强项 | 研发、临床、注册 | 两款产品获批，舒沃替尼获得美国 FDA 加速批准 |
| 成本优势 | 弱 | 创新药研发、临床和商业化投入高，规模效应尚未充分形成 |
| 活动系统 | 正在形成 | 研发平台、临床执行、监管能力和商业化开始联动 |
| 财务成熟度 | 中低 | 商业化仍处爬坡期，利润和现金流尚不能像成熟药企一样验证 |
| 优势持续性 | 中高但不确定 | 取决于专利、临床证据、适应症扩展、竞品和支付环境 |

## 6. 投资判断

迪哲医药属于“战略质量较高、财务成熟度较低、估值高度依赖成功概率”的公司。其估值不能简单使用成熟药企市盈率，而应采用风险调整后的产品管线估值：

```text
公司价值 ≈ 已上市产品风险调整后现金流
        + 在研管线成功概率 × 峰值销售折现值
        + 平台与授权期权价值
        - 研发、商业化和融资消耗
```

## 7. 失效条件

- 核心产品真实世界疗效或安全性不及预期；
- 竞争药物在疗效、价格或适用范围上明显占优；
- 商业化销售费用高企但收入爬坡缓慢；
- 医保降价显著压缩单位经济性；
- 后续管线连续失败，平台重复性被证伪；
- 现金消耗迫使公司高频融资并显著摊薄股东。

**结论**：迪哲医药验证了波特的差异化聚焦，但尚未完全验证可持续财务回报。投资者应将“临床差异化”和“股东回报兑现”分开评估。

# 案例二：宁德时代——规模、工艺与技术共同形成活动系统

## 1. 优势类型

宁德时代并非单纯低价竞争。其优势更接近：

```text
规模与制造效率形成成本优势
+ 研发、产品性能和客户协同形成差异化
+ 全球供应链与产能网络扩大竞争范围
```

## 2. 价值链优势

- 上游材料与供应链管理；
- 电芯、模组和系统设计；
- 大规模制造和良率控制；
- 研发平台与多技术路线；
- 主机厂联合开发和认证；
- 储能、换电和回收等互补业务；
- 全球产能和服务网络。

这些活动相互强化：更大出货量带来学习和采购优势，更强研发提高产品性能，更深客户合作增加认证和转换成本。

## 3. 财务信号

公开资料显示，宁德时代 2024 年营业收入约 3620.13 亿元，同比下降约 9.7%；归母净利润约 507.45 亿元，同比增长约 15%。收入下降而利润增长，至少阶段性说明产品结构、成本控制和经营效率对价格压力形成缓冲。

但不能据此断言优势永久存在。动力电池行业仍受价格竞争、技术路线变化、客户自研、海外政策和资本开支影响。

## 4. 失效条件

- 电池技术路线发生重大替代；
- 客户集中度和议价权进一步上升；
- 同行制造良率和成本快速追平；
- 海外政策限制提高全球化成本；
- 扩产导致利用率下降和资本回报恶化。

**结论**：宁德时代是“多项活动协同”比“单个技术专利”更重要的典型案例。

# 案例三：美的集团——运营效率与广泛价值链协同

## 1. 优势类型

美的更接近广范围成本优势，同时通过产品、品牌、渠道和全球运营提供适度差异化。

## 2. 价值链来源

- 大规模采购和制造；
- 自动化与数字化运营；
- 多品类共享供应链、渠道和售后；
- 全球生产和销售网络；
- 家电与工业技术业务之间的技术、客户和管理复用；
- 持续改善库存、交付和运营效率。

## 3. 波特框架验证

美的的关键不是“品类多”，而是多个业务能否共享采购、研发、制造、渠道和组织能力。如果共享收益高于协调成本，多元化形成横向战略；若新业务只消耗资本，则会破坏优势。

## 4. 跟踪重点

- 各业务 ROIC 与自由现金流；
- 海外收入和本地化盈利；
- 多品类协同是否降低费用率；
- 工业业务并购后的资本回报；
- 家电需求周期和价格竞争。

**结论**：美的说明成本优势可来自整套运营系统，而非简单压低工资或材料价格。

# 案例四：贵州茅台——稀缺供给、品牌与渠道构成差异化

## 1. 优势类型

茅台的核心是广范围差异化，来源包括产区条件、工艺周期、品牌历史、社交属性、渠道和稀缺性。

## 2. 客户价值

客户购买的不只是饮品功能，还包括礼赠、宴请、身份表达、收藏和信任。其价值同时存在于实际品质与感知价值。

## 3. 活动系统

```text
产区与工艺限制供给
→ 长周期生产形成稀缺
→ 品牌和渠道强化认知
→ 价格与稀缺互相加强
→ 高现金流反哺产能、质量和品牌维护
```

## 4. 风险

- 社会消费习惯变化；
- 政策和公务消费约束；
- 渠道价格倒挂；
- 年轻消费者偏好变化；
- 供给扩张削弱稀缺感；
- 高估值透支增长。

**结论**：茅台说明差异化可来自物理稀缺与社会认知共同作用，但品牌同样需要持续维护。

# 案例五：通源石油——催化交易不等于持续竞争优势

## 1. 业务特征

油服企业的需求受油价、上游资本开支、地缘事件和客户预算影响，周期属性显著。股价可能因战争、油价上涨和资金轮动出现强催化，但这不自动意味着企业拥有长期竞争优势。

## 2. 波特框架下的研究重点

- 技术和服务是否显著降低客户单井成本或提高产量；
- 客户集中度及议价权；
- 设备利用率和固定成本；
- 海外业务的政治与汇率风险；
- 订单能见度和回款质量；
- 同行进入壁垒与价格竞争。

## 3. 投资分类

通源石油更适合被分为：

```text
周期与事件驱动交易标的
≠ 已被充分验证的长期复利型竞争优势标的
```

这并不否定交易价值，而是要求使用不同仓位、止损和卖出规则。不能用“油价长期上涨”替代对公司价值链和现金流的研究。

# 六、五家公司横向比较

| 公司 | 主要战略 | 优势成熟度 | 财务可验证性 | 主要风险 | 更适合的研究框架 |
|---|---|---:|---:|---|---|
| 迪哲医药 | 差异化聚焦 | 中 | 中低 | 临床、商业化、竞品、融资 | rNPV + 管线概率 |
| 宁德时代 | 成本 + 差异化 | 高 | 高 | 技术替代、价格战、政策 | ROIC + 成本曲线 |
| 美的集团 | 成本领先 + 协同 | 高 | 高 | 周期、并购、海外经营 | 自由现金流 + 分部 ROIC |
| 贵州茅台 | 品牌与稀缺差异化 | 高 | 高 | 消费偏好、政策、估值 | 品牌持续性 + 现金流 |
| 通源石油 | 周期与项目能力 | 中低 | 中 | 油价、资本开支、回款 | 周期位置 + 订单 + 交易纪律 |

# 七、最终验证结论

1. 迪哲医药证明小公司可通过差异化聚焦绕开大药企的规模优势。
2. 宁德时代证明最强护城河通常是多项价值活动协同，而非单项技术。
3. 美的证明成本优势来自全价值链运营效率。
4. 茅台证明客户感知价值可以形成巨大溢价，但仍需防范偏好和政策变化。
5. 通源石油证明股价催化、行业景气和持续竞争优势是三个不同概念。
