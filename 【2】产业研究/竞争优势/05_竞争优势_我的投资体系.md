# 我的投资体系：竞争优势驱动的“基本面 × 预期差 × 风险控制”体系

> 版本：v1.0  
> 目标：五年内形成可复制、可审计、可迭代的职业投资流程。  
> 核心原则：我追求的是长期正期望与可控回撤，而不是每次判断正确。

## 一、体系总纲

我的投资收益来源于三类机会：

1. **优质复利**：企业拥有可持续竞争优势，内在价值持续增长。
2. **周期反转**：行业供需、价格和资本开支从底部改善。
3. **事件与预期差**：基本面或催化出现边际变化，但市场尚未充分定价。

三类机会使用不同的研究方法、持有周期和卖出规则。不得用长期逻辑掩盖事件交易失败，也不得因短期波动轻易卖出已经验证的复利资产。

## 二、投资流程

```text
投资想法
→ 行业结构筛选
→ 公司价值链分析
→ 竞争优势分类
→ 财务验证
→ 优势持续性与反证
→ 估值和隐含预期
→ 催化与时间窗口
→ 仓位与风险预算
→ 跟踪、复盘和退出
```

## 三、第一层：行业结构

### 必答问题

- 行业五力结构如何？
- 利润池在价值链哪一环？
- 行业处于导入、成长、成熟、衰退还是周期底部？
- 供给扩张速度是否超过需求？
- 客户、供应商、监管和替代品谁掌握定价权？

### 一票否决

- 长期供给无序扩张且无退出机制；
- 产品完全同质化、客户切换成本极低；
- 资本回报长期低于资本成本；
- 财务、治理或监管风险无法评估。

## 四、第二层：价值链与竞争优势

### 1. 画出价值链

对每家公司至少画出：

```text
上游输入 → 核心研发/生产 → 渠道/交付 → 客户使用 → 售后/复购
```

并标记每一环的：收入、成本、资本占用、议价权、关键能力和风险。

### 2. 明确优势类型

- 低成本；
- 差异化；
- 成本聚焦；
- 差异化聚焦；
- 暂无优势，仅周期或事件驱动。

### 3. 写出活动联系

至少找出三项互相强化的活动。例如：

```text
研发领先 → 产品性能提升 → 客户采用增加
→ 数据与反馈增多 → 下一代研发更快
```

若只找到一个孤立优势，降低持续性评分。

## 五、第三层：财务验证

### 核心指标

| 维度 | 指标 | 目的 |
|---|---|---|
| 价格与差异化 | 毛利率、单价、产品结构 | 判断客户是否付费 |
| 成本优势 | 单位成本、费用率、周转率 | 判断相对效率 |
| 资本效率 | ROIC、固定资产周转 | 判断增长是否创造价值 |
| 现金质量 | 经营现金流、自由现金流 | 判断利润真实性 |
| 增长质量 | 收入、毛利、现金流同步性 | 排除低质量扩张 |
| 财务安全 | 净负债、利息覆盖、现金 runway | 控制融资与偿债风险 |

### 财务规则

- 成熟企业：ROIC 应在完整周期内高于资本成本；
- 周期企业：看成本曲线和资产负债表，不机械看静态市盈率；
- 创新药：看现金储备、研发消耗、产品 rNPV 和融资摊薄；
- 高成长企业：收入增长必须逐步转化为单位经济性和现金流改善。

## 六、第四层：持续性与反证

每个标的必须写出至少五项优势衰减指标：

1. 相对毛利率持续下降；
2. 市场份额下降或获客成本上升；
3. 竞争者产品性能、成本或渠道追平；
4. 客户集中度和议价权上升；
5. 替代技术渗透加快；
6. 研发效率下降；
7. 管理层跨界扩张；
8. ROIC 和自由现金流恶化。

出现一项不立即卖出；出现两至三项并形成趋势，重新估值并降低仓位。

## 七、第五层：估值与预期差

### 1. 估值原则

- 估值不是寻找一个精确数字，而是构建合理区间；
- 至少做悲观、基准、乐观三种情景；
- 反推市场当前价格隐含的增长率、利润率和成功概率；
- 只有当预期收益明显高于风险成本时才买入。

### 2. 分类估值

| 公司类型 | 主要方法 |
|---|---|
| 稳定复利 | DCF、自由现金流收益率、合理 PE |
| 周期股 | 中周期利润、PB、重置成本、成本曲线 |
| 创新药 | 风险调整净现值 rNPV、峰值销售、现金消耗 |
| 平台成长 | 分部估值、单位经济性、长期利润率 |
| 事件交易 | 情景概率、盈亏比、催化时间 |

### 3. 买入最低要求

```text
预期收益空间 / 可接受损失 ≥ 2.5
```

对于二元事件较强的创新药或事件交易，要求更高安全边际，并缩小仓位。

## 八、评分卡：100 分制

| 模块 | 权重 | 评分内容 |
|---|---:|---|
| 行业结构 | 15 | 利润池、供需、五力、周期位置 |
| 客户价值 | 15 | 痛点、支付意愿、黏性、替代 |
| 竞争优势 | 20 | 成本/差异化/聚焦及活动系统 |
| 持续性 | 15 | 复制难度、技术和政策风险 |
| 管理与资本配置 | 10 | 战略纪律、激励、并购、回购分红 |
| 财务质量 | 10 | ROIC、现金流、负债、增长质量 |
| 估值 | 10 | 安全边际、隐含预期、情景收益 |
| 催化与时间 | 5 | 业绩、产品、政策、周期拐点 |

### 评分与行动

- **低于 60**：放弃；
- **60–69**：观察，不持仓；
- **70–79**：试探仓，通常 2%–5%；
- **80–89**：标准仓，通常 5%–10%；
- **90 以上**：高确信标的，但单一股票原则上不超过 15%。

创新药、资源股和强事件标的即使评分高，也因二元风险和波动性降低仓位上限。

## 九、仓位体系

### 1. 账户分层

- **核心复利仓：50%–70%**  
  竞争优势已被商业和财务验证，持有期以年计。

- **成长与拐点仓：20%–35%**  
  优势正在形成，需跟踪产品、份额、利润率和现金流。

- **事件交易仓：0%–15%**  
  地缘、政策、题材、财报或临床事件，必须有明确止损和期限。

- **现金：10%–30%**  
  根据市场风险偏好、估值和机会密度动态调整。

### 2. 单股规则

- 初始仓位通常不超过 5%；
- 只有在新证据提高成功概率后加仓，不因下跌本身加仓；
- 创新药单股初始仓 2%–3%，上限通常 8%；
- 高波动事件仓单笔最大可承受损失不超过总资产 1%；
- 禁止借贷加仓和单票满仓。

## 十、买入规则

同时满足：

1. 我能用三句话说清公司价值链和优势；
2. 优势有经营或财务证据；
3. 至少列出三个反证条件；
4. 估值存在安全边际；
5. 催化或价值兑现路径可识别；
6. 仓位与最大损失已计算；
7. 买入原因不是害怕踏空。

## 十一、加仓规则

仅在以下情形加仓：

- 新产品、订单、临床或财报提高内在价值；
- 竞争优势进一步被验证；
- 股价下跌但基本面与价值判断未变，且估值进入更高赔率区间；
- 组合总风险仍在预算内。

禁止因“已经亏损很多”或“想摊低成本”加仓。

## 十二、卖出规则

### 基本面卖出

- 核心竞争优势被证伪；
- 行业结构永久恶化；
- 管理层资本配置失控；
- 现金流和资产负债表显著恶化；
- 替代技术改变原有价值链。

### 估值卖出

- 股价已反映乐观情景；
- 未来三年预期收益低于无风险收益与风险补偿；
- 存在赔率明显更高的替代标的。

### 交易卖出

- 催化兑现；
- 时间窗口结束；
- 预设止损触发；
- 价格行为与原假设明显背离。

## 十三、迪哲医药应用模板

### 投资逻辑

- 类型：差异化聚焦；
- 优势活动：分子发现、临床开发、全球注册；
- 已验证事件：舒沃替尼中美获批，戈利昔替尼中国获批；
- 待验证环节：商业化、适应症扩展、后续管线、现金流。

### 关键跟踪

- 产品销售爬坡和患者覆盖；
- 医保及价格变化；
- 海外销售或合作进展；
- 临床数据和监管节点；
- 同适应症竞品；
- 研发费用、现金余额和融资计划。

### 仓位规则

由于创新药具有临床、监管和商业化二元风险，不能按成熟消费股仓位配置。任何单次临床或审批事件前，先计算失败情景对总资产的损失。

## 十四、量化主导和快速轮动市场中的应对

量化交易擅长速度、短期统计规律和资金博弈。个人投资者不应在毫秒级竞争，而应利用以下优势：

- 可选择不交易；
- 可持有低流动性、长兑现周期的研究成果；
- 可理解公司价值链和产业变化；
- 可在市场情绪极端时逆向；
- 可把基本面研究与简单量化过滤结合。

### 我的执行方式

```text
基本面决定买什么
估值决定买多少
催化决定何时关注
价格与资金决定如何执行
风险预算决定能否活下来
```

技术面和资金面只用于入场、减仓和风险控制，不能替代竞争优势研究。

## 十五、复盘制度

### 每日

- 记录持仓重大信息；
- 检查是否触发风险条件；
- 不因盘中波动临时修改长期逻辑。

### 每周

- 更新行业景气、资金风格和关键数据；
- 对持仓评分卡重新打分；
- 检查组合集中度和相关性。

### 每月

- 归因收益：基本面、估值、情绪、运气；
- 统计胜率、盈亏比、最大回撤和换手；
- 找出一次最差决策并写出流程修复措施。

### 每季度

- 完整更新价值链、竞争优势和估值；
- 删除已经失效的旧叙事；
- 比较公司实际表现与原预测，而不是与股价比较。

## 十七、我的投资纪律宣言

1. 我不靠频繁交易证明自己。
2. 我不把新闻催化误认为竞争优势。
3. 我不把好公司误认为任何价格都值得买。
4. 我不在没有反证条件时建立重仓。
5. 我先控制永久损失，再追求收益。
6. 我只在新证据提高赔率时加仓。
7. 我接受错过，不接受失控。
8. 我通过持续复盘，让投资体系比单次收益更重要。
