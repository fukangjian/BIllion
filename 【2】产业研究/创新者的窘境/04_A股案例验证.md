# 《创新者的窘境》A股案例验证

> 说明：用户示例中的“迪泽医药”应为 **迪哲医药（688192.SH）**。
>
> 案例判断采用六个问题：
>
> 1. 是否服务非消费者或被过度满足的客户？
> 2. 初始产品是否按传统指标看“不够好”？
> 3. 是否更便宜、更简单、更方便或更易获得？
> 4. 是否存在持续改善并向上移动的技术路径？
> 5. 是否配套可持续的新商业模式和价值网络？
> 6. incumbent 初期是否缺乏反击动机？

---

## 案例一：传音控股——A股中较典型的新市场颠覆案例

### 1. 现象

传音没有优先进入欧美、中国等竞争最激烈、参数要求最高的智能手机市场，而是长期聚焦非洲等新兴市场，围绕当地消费者的真实使用条件进行本地化设计和渠道建设。

典型差异包括：

- 更适应当地肤色的拍照算法；
- 多卡多待；
- 长续航；
- 防尘、防汗等适配；
- 广泛线下渠道；
- 多品牌覆盖不同价格带。

它最初不是用最高端参数挑战全球旗舰手机，而是把大量此前难以获得适配产品的消费者转化为手机用户。

### 2. 六问检验

| 问题 | 判断 | 说明 |
|---|---|---|
| 服务非消费者或被忽视客户 | 是 | 聚焦全球主流品牌关注不足的新兴市场 |
| 初始性能不如主流旗舰 | 是 | 早期核心优势不是处理器和旗舰参数 |
| 更便宜、方便、易获得 | 是 | 价格、渠道和本地化构成综合可获得性 |
| 能否持续改善并向上移动 | 是 | 从功能机向智能机、从低端向中高端扩展 |
| 新商业模式和价值网络 | 是 | 本地渠道、品牌矩阵、供应链和售后体系 |
| incumbent 初期缺乏反击动机 | 较强 | 低客单、复杂渠道和区域碎片化降低吸引力 |

### 3. 理论结论

传音控股符合“新市场颠覆”的大部分特征，是本学习包中最接近经典模型的A股案例。

### 4. 投资观察点

- 智能手机渗透率提升后，增长是否从用户扩张转向份额竞争；
- 中高端化是否成功；
- 非洲之外的新市场是否复制；
- 渠道库存和汇率风险；
- AI手机和生态产品是否形成新增长；
- 毛利改善是否来自品牌提升，而非短期产品结构。

### 5. 失效条件

- 本地化优势被全球品牌快速复制；
- 渠道库存恶化；
- 中高端化长期失败；
- 核心市场竞争导致价格和毛利持续下滑；
- 新市场扩张无法覆盖成熟市场增速下降。

## 案例二：石头科技——从生态链低成本入口到自主品牌上移

### 1. 现象

石头科技早期通过小米生态链进入智能清洁市场，借助成熟渠道、供应链和高性价比定位降低消费者首次使用扫地机器人的门槛。随后逐渐发展自主品牌，并通过导航、避障、基站、自清洁等技术向中高端市场上移。

### 2. 六问检验

| 问题 | 判断 | 说明 |
|---|---|---|
| 服务非消费者或被过度满足客户 | 部分符合 | 让原本不愿购买高价机器人产品的家庭进入市场 |
| 初始性能不如高端产品 | 部分符合 | 早期更强调高性价比和基础功能 |
| 更便宜、方便、易获得 | 是 | 小米渠道和价格策略降低试用门槛 |
| 能否持续改善并向上移动 | 是 | 技术、品牌和价格带持续上移 |
| 新商业模式和价值网络 | 是 | 生态链入口、线上渠道、轻资产供应链 |
| incumbent 初期缺乏反击动机 | 部分符合 | 传统清洁电器厂商早期对智能导航重视不足，但竞争后来快速加剧 |

### 3. 理论结论

石头科技具有颠覆路径特征，但不是最纯粹的低端颠覆。它更像“生态链降低市场进入门槛 + 技术持续升级 + 品牌向上”的混合案例。

### 4. 投资观察点

- 海外收入和品牌份额；
- 新品迭代是否形成真实换机需求；
- 研发投入能否维持差异化；
- 科沃斯、追觅等竞争者是否压缩利润；
- 高端化是否导致产品过度设计；
- 销售费用增长是否快于收入。

### 5. 反向启示

石头科技自己也可能面临新的“创新者窘境”：当公司进入高端、追求更高客单价后，可能忽视更便宜、更简单的新 entrant。因此，不能只研究它如何颠覆别人，也要研究它是否正在成为被颠覆的 incumbent。

## 案例三：比亚迪——新能源产业替代中的混合型创新

### 1. 现象

比亚迪从电池业务起步，通过电池、电机、电控、半导体和整车垂直整合进入汽车产业。早期新能源汽车在续航、补能便利性和使用习惯上不如成熟燃油车，但在运营成本、能源效率、城市通勤和政策支持场景中具有优势。

随后，电池性能、整车平台、充电速度、成本和产品矩阵持续改善，新能源汽车从特定场景进入主流市场。

### 2. 六问检验

| 问题 | 判断 | 说明 |
|---|---|---|
| 服务非消费者或被过度满足客户 | 部分符合 | 早期包含公交、出租和限牌城市等特殊场景，后扩展大众市场 |
| 初始性能不如 incumbent | 是 | 早期续航、补能、残值和使用便利存在明显短板 |
| 更便宜、方便、易获得 | 阶段性符合 | 使用成本更低，后期依靠规模和供应链降低售价 |
| 能否持续改善并向上移动 | 是 | 电池、平台、车型和品牌持续上移 |
| 新商业模式和价值网络 | 是 | 垂直整合、直营与经销结合、能源系统协同 |
| incumbent 初期缺乏反击动机 | 较强 | 传统车企需保护发动机、变速箱、经销和售后利润池 |

### 3. 理论结论

新能源汽车替代燃油车具有颠覆成分，但不能简单把所有新能源车企都称为颠覆者。比亚迪是技术突破、政策驱动、规模制造、供应链整合和产业替代共同作用的混合案例。

### 4. 投资观察点

- 单车盈利和价格竞争；
- 海外产能与贸易壁垒；
- 智能化能力是否补齐；
- 垂直整合在规模下降时是否变成固定成本压力；
- 高端品牌是否真正建立品牌溢价；
- 资本开支和经营现金流匹配度。

### 5. 对 incumbent 的启示

传统车企不是不知道电动车，而是旧有发动机、变速箱、供应商、经销商和利润结构使转型成本极高。这正是组织流程和价值网络锁定的典型表现。

## 案例四：迪哲医药——创新药是突破性创新，但不是典型低端颠覆

### 1. 先给结论

迪哲医药是高质量创新药公司的研究案例，但从 Christensen 的严格定义看，它更接近：

> **突破性持续创新 + 小型独立研发组织优势**

而不是低端颠覆或新市场颠覆。

### 2. 为什么不是典型颠覆

创新药通常具备：

- 更强疗效或更优安全性；
- 高研发投入；
- 严格临床和监管门槛；
- 专业医生和医院渠道；
- 较高定价；
- 服务现有患者和医疗体系。

它不是从“更差但更便宜”的产品进入低端，也不是主要依靠简单、便宜和便利把非消费者转化为消费者。其竞争逻辑仍然是疗效、安全性、适应症、临床证据和监管批准，这属于既有医药价值网络中的高性能竞争。

### 3. 六问检验

| 问题 | 判断 | 说明 |
|---|---|---|
| 服务非消费者或被过度满足客户 | 弱 | 服务未满足医疗需求，但患者本身属于既有医疗市场 |
| 初始性能不如主流产品 | 否 | 创新药的核心是疗效和安全性改善 |
| 更便宜、简单、易获得 | 通常否 | 研发和定价通常不具备低端属性 |
| 能否持续改善并向上移动 | 是 | 可通过适应症扩展、全球临床和联合治疗扩大价值 |
| 新商业模式和价值网络 | 部分符合 | 小型研发组织、全球授权和合作模式与传统药企不同 |
| incumbent 初期缺乏反击动机 | 否或较弱 | 大药企高度关注高价值创新资产，并购和授权积极 |

### 4. 迪哲医药具备的“entrant 优势”

虽然不是经典颠覆，迪哲仍体现了《创新者的窘境》的组织逻辑：

- 小团队可以聚焦少数高价值靶点；
- 决策链条短；
- 不需要保护庞大的成熟药品收入；
- 研发资源可以集中在差异化管线；
- 可通过全球授权把大药企的商业化能力转化为自身价值。

### 5. 截至2026年7月的重要验证

公开报道显示：

- 舒沃替尼（Sunvozertinib，Zegfrovy）于2025年7月获得美国FDA加速批准，用于特定EGFR exon 20插入突变非小细胞肺癌患者；
- 2026年7月14日，阿斯利康与迪哲医药就 Zegfrovy 达成全球独家许可安排，报道披露首付款约6亿美元、潜在总额最高约15亿美元，并包含分级销售提成；
- 该交易验证了资产的全球临床和商业价值，但并不自动证明公司所有管线都成功，也不意味着任何估值都合理。

### 6. 对投资者最重要的分析框架

研究迪哲医药应使用“创新药资产估值”，而不是简单套用颠覆式创新框架。

#### 资产层

- 适应症患者数；
- 竞争格局；
- 临床疗效和安全性；
- 获批概率；
- 上市时间；
- 渗透率；
- 定价和医保；
- 专利期限；
- 海外权益；
- 里程碑和销售分成。

#### 公司层

- 管线集中度；
- 研发费用；
- 现金储备和融资需求；
- 商业化团队效率；
- 核心人才稳定性；
- 后续管线是否形成平台能力。

#### 股票层

- 市值已经隐含多少峰值销售；
- 授权首付款是否属于一次性收益；
- 市场是否把单个产品成功外推到全部管线；
- 股价是否在公告前已透支；
- 催化兑现后是否出现“利好出尽”。

### 7. 迪哲医药的投资失效条件

- 一线或新增适应症临床数据不达预期；
- 安全性信号显著恶化；
- 竞争药物疗效、给药方式或商业化显著领先；
- 商业化放量低于患者和渠道假设；
- 后续管线无法证明平台化研发能力；
- 市值明显超过概率加权资产价值；
- 过度依赖单一产品或单一合作方。

## 案例五：恒瑞医药——incumbent 如何尝试自我颠覆

### 1. 案例意义

恒瑞医药拥有成熟产品、销售体系、现金流和研发能力，同时需要从仿制药和传统销售驱动模式转向创新药和国际化。这是典型的 incumbent 转型问题。

### 2. 需要观察的不是研发费用，而是组织重构

- 创新药项目是否按全球竞争标准决策；
- 是否愿意停止低回报项目；
- 国际临床和BD是否形成独立能力；
- 销售体系是否从渠道驱动转向循证医学和准入；
- 是否允许新产品蚕食旧产品；
- 考核是否从短期收入转向管线价值。

### 3. 理论结论

incumbent 不一定失败。若能建立独立组织、调整价值观、利用资金和商业化资源，它可能完成自我更新。但转型难点通常不是技术，而是资源、流程和价值观的冲突。

## 五个案例的综合比较

| 公司 | 创新类型判断 | 颠覆纯度 | 主要优势 | 核心风险 |
|---|---|---:|---|---|
| 传音控股 | 新市场颠覆 | 高 | 本地化、渠道、品牌矩阵 | 市场成熟、竞争和汇率 |
| 石头科技 | 混合型颠覆 | 中高 | 技术迭代、生态链、品牌上移 | 竞争加剧、过度高端化 |
| 比亚迪 | 产业替代+混合型颠覆 | 中 | 垂直整合、规模、技术平台 | 价格战、资本开支、智能化 |
| 迪哲医药 | 突破性持续创新 | 低 | 聚焦研发、全球资产、授权能力 | 临床、商业化、管线集中、估值 |
| 恒瑞医药 | incumbent 自我更新 | 不适用 | 现金流、研发和商业化资源 | 组织惯性、国际化和效率 |

## 案例验证后的最终结论

### 结论一

不能把“创新药、AI、新能源、机器人”直接等同于颠覆式创新。必须分析客户入口和商业模式。

### 结论二

A股中最值得研究的不只是“谁的技术最好”，而是：

- 谁服务了过去没人服务的客户；
- 谁的成本结构允许在低价市场盈利；
- 谁能从边缘市场持续向主流上移；
- 谁让 incumbent 陷入不愿反击或无法反击的困境。

### 结论三

迪哲医药的价值不在“颠覆”标签，而在创新药资产质量、全球临床、授权交易、商业化和后续管线。使用错误理论标签，可能导致错误估值。
