# 我的投资体系：颠覆式创新与产业变迁投资系统 1.0

## 一、体系定位

### 1. 我的目标

在未来五年逐步建立职业投资者能力，不依赖短期消息和高频交易，而是通过：

- 产业趋势研究；
- 商业模式验证；
- 公司竞争优势；
- 催化剂跟踪；
- 估值和赔率；
- 仓位与风控；

形成可复制、可记录、可复盘的投资流程。

### 2. 我的优势

作为嵌入式软件架构设计师，我具备：

- 系统思维；
- 技术理解能力；
- 架构和模块化分析能力；
- 对产品迭代和工程约束的敏感度；
- 长时间处理复杂信息的能力。

这些能力适合研究AI、半导体、机器人、汽车电子、创新药平台、工业软件和智能硬件等产业。

### 3. 我的主要弱点

- 容易被强催化和短期涨幅强化信念；
- 容易把产业趋势正确等同于个股正确；
- 对高弹性标的产生过高仓位冲动；
- 容易在市场快速轮动时频繁切换；
- 可能重视故事和边际变化，低估估值与资金风险偏好。

因此，本体系必须用流程约束主观冲动。

---

## 二、体系总公式

```text
预期收益 = 产业空间 × 公司胜率 × 商业化兑现 × 估值修复 × 市场催化
            ---------------------------------------------------
                     失败概率 × 估值透支 × 仓位风险
```

更实际的表达是：

> 投资质量 = 方向正确性 × 证据强度 × 赔率 × 仓位纪律

任何一项接近零，整体投资质量都会显著下降。

## 三、三类创新投资标的

### A类：真颠覆者

特征：

- 从低端或非消费者进入；
- 更便宜、简单、方便；
- 商业模式结构性不同；
- incumbent 初期不愿反击；
- 有明确向上移动路径。

适用估值：用户数、渗透率、单位经济、市场份额、长期利润池。

### B类：突破性持续创新者

特征：

- 技术或产品显著更强；
- 服务现有主流或高端客户；
- 依靠研发、专利、临床、品牌和渠道竞争；
- incumbent 会积极参与。

创新药、先进设备、高端芯片多属于此类。

适用估值：概率调整现金流、资产价值、竞争格局、研发成功率。

### C类：自我更新的 incumbent

特征：

- 有成熟现金流和资源；
- 面临新技术和新商业模式冲击；
- 通过独立组织、并购或新品牌完成转型。

适用估值：旧业务现金牛价值 + 新业务期权价值 - 转型成本。

## 四、研究流程：十步法

## 第一步：定义客户和待完成任务

回答：

- 客户是谁？
- 客户真正要解决的问题是什么？
- 现有方案为什么昂贵、复杂或不方便？
- 哪些人目前没有消费？
- 哪些客户被过度满足？

没有明确客户，不进入下一步。

## 第二步：判断创新类型

使用三个问题：

1. 是让现有产品更好吗？
2. 是让低端客户以更低成本获得“够用”产品吗？
3. 是让原本无法消费的人开始消费吗？

输出必须是：持续性创新、低端颠覆、新市场颠覆、混合型或无法判断。

## 第三步：绘制价值网络

至少画出：

```text
技术/原料 → 生产 → 渠道 → 购买者 → 使用者 → 支付者 → 利润池
```

特别识别：购买者、使用者和支付者是否为同一主体。医疗行业中三者常不同，这是创新药商业化的关键。

## 第四步：比较性能轨迹

建立三条曲线：

- incumbent 产品性能；
- entrant 产品性能；
- 客户最低需求。

重点不是 entrant 今天是否领先，而是未来何时达到主流门槛。

## 第五步：验证商业模式

核心指标：

- 客单价；
- 毛利率；
- 获客成本；
- 复购率；
- 渠道费用；
- 交付成本；
- 存货周转；
- 研发和销售费用率；
- 单位经济；
- 现金消耗。

低价但长期亏损，不视为颠覆优势。

## 第六步：判断 incumbent 的反应

分成四种情况：

| 动机 | 能力 | 判断 |
|---|---|---|
| 低 | 低 | entrant 最佳窗口 |
| 低 | 高 | 初期安全，后期需警惕 |
| 高 | 低 | incumbent 会投入但转型困难 |
| 高 | 高 | entrant 胜率最低 |

## 第七步：寻找向上突破证据

至少出现两项才可从观察仓升级：

- 客单价提升；
- 进入更高等级客户；
- 产品性能达到主流门槛；
- 毛利率改善；
- 品牌溢价形成；
- 新渠道成功；
- 海外市场验证；
- 竞争者退出；
- incumbent 被迫降价或推出子品牌。

## 第八步：检查财务生存能力

早期创新公司必须回答：

- 账上现金可支撑多少个月？
- 未来两年资本开支和研发投入？
- 是否需要增发或借款？
- 融资时是否可能大幅稀释？
- 核心业务何时达到盈亏平衡？

原则：现金跑道不足18个月且融资不确定时，不允许重仓。

## 第九步：进行三情景估值

### 悲观情景

- 产品改善失败；
- 市场规模低于预期；
- incumbent 有效反击；
- 毛利和现金流恶化。

### 基准情景

- 公司按行业平均速度商业化；
- 市占率和盈利达到合理水平；
- 估值回归行业中枢。

### 乐观情景

- 完成向上突破；
- 市占率快速提升；
- 形成平台或生态；
- 国际化成功。

要求：买入价格应在悲观情景下可承受，在基准情景下有合理收益，而不是必须依赖乐观情景才能盈利。

## 第十步：加入市场与催化确认

基本面正确不代表立即上涨。A股需要同时观察：

- 行业相对强度；
- 板块涨停和赚钱效应；
- 成交量和换手；
- 机构资金与主力承接；
- 催化是否为正式公告；
- 股价是否已经提前反映；
- 大盘风险偏好和折现率。

我的原则：

> 基本面决定是否值得买，市场结构决定何时买，仓位决定能否活下来。

| 组织与管理 | 10 | 是否具备独立组织、执行力和治理能力 |
| 竞争与 incumbent 反应 | 10 | 对手是否有动机和能力反击 |
| 财务与现金跑道 | 10 | 现金流、融资、资本开支是否安全 |
| 向上突破证据 | 5 | 是否已从边缘进入主流 |

| **合计** | **100** |  |

### 评分对应操作

- **80—100分：核心候选。** 可以分阶段建立中等仓位，但仍不得一次性满仓。
- **70—79分：重点跟踪。** 建立观察仓，等待关键验证节点。
- **60—69分：事件型机会。** 仅适合小仓催化交易，不作为长期核心仓。
- **60分以下：放弃。** 故事可能精彩，但证据不足或赔率不佳。

## 六、仓位体系：以100万元本金为例

### 1. 账户结构

| 类型 | 目标比例 | 说明 |
|---|---:|---|
| 现金与低风险仓 | 20%—40% | 用于回撤保护和等待机会 |
| 核心成熟仓 | 30%—45% | 商业模式和现金流已验证 |
| 创新成长仓 | 20%—30% | 处于产业扩张和业绩兑现阶段 |
| 高不确定期权仓 | 5%—10% | 临床、技术验证或重大催化标的 |

### 2. 单只股票仓位上限

- 初始观察仓：3%—5%，即3万—5万元；
- 数据验证后：6%—8%；
- 成为核心仓：8%—12%；
- 极高确信度上限：15%；
- 未经过完整验证，禁止满仓单一个股。

### 3. 三段式建仓

```text
第一笔30%：逻辑成立，价格进入合理区间
第二笔30%：关键数据或公告验证
第三笔40%：趋势、成交和业绩共同确认
```

若第一笔后逻辑被证伪，损失被限制在账户可承受范围内。

## 七、创新药专项体系：以迪哲医药为例

## 1. 不用传统PE作为主要估值工具

创新药公司早期利润受研发和商业化投入影响，PE意义有限。采用：

```text
公司价值 = 已上市产品风险调整价值
         + 在研管线风险调整价值
         + 现金
         - 有息负债
         - 未来融资稀释
```

## 2. 单个药物的风险调整价值

```text
rNPV = Σ(未来销售额 × 净利润率 × 成功概率 ÷ 折现因子)
       - 后续研发和商业化投入
```

### 概率必须分阶段

- 临床前；
- I期；
- II期；
- III期；
- 注册审评；
- 获批上市；
- 商业化放量。

不能因为一次积极数据就按100%成功估值。

## 3. 迪哲医药跟踪表

| 模块 | 关键指标 |
|---|---|
| 舒沃替尼 | 国内销售、美国商业化、适应症扩展、竞争药物 |
| 戈利昔替尼 | 患者覆盖、放量速度、海外开发和安全性 |
| 全球授权 | 首付款到账、里程碑条件、分成比例、权益范围 |
| 后续管线 | 是否证明平台化研发，而非单一产品偶然成功 |
| 现金流 | 研发投入、商业化投入、未来融资需求 |
| 估值 | 市值隐含峰值销售和成功概率 |
| 市场结构 | 公告后成交、换手、资金承接和利好兑现程度 |

## 4. 迪哲医药买入条件

至少满足以下五项中的四项：

- 核心产品临床或商业化数据继续验证；
- 新适应症扩大可服务市场；
- 全球合作条款显著提升资产价值；
- 现金跑道覆盖未来24个月；
- 市值低于基准情景rNPV并保留30%以上安全边际。

## 5. 迪哲医药减仓条件

- 股价快速上涨但基本面增量有限；
- 市值接近或超过乐观情景价值；
- 关键临床节点前仓位过高；
- 板块退潮且个股失去承接；
- 授权收入被市场错误当成可持续经营利润。

## 6. 迪哲医药清仓条件

- 核心临床失败；
- 重大安全性问题；
- 商业化明显低于最低假设；
- 后续管线连续失败，平台逻辑被证伪；
- 管理层或治理出现重大诚信问题。

## 九、卖出体系

### 1. 逻辑卖出

- 客户需求被证伪；
- 技术轨迹无法达到主流门槛；
- 商业模式无法盈利；
- incumbent 有效反击；
- 管理层资本配置恶化；
- 原有竞争优势被复制。

### 2. 估值卖出

- 当前价格必须依赖乐观情景才能获得合理回报；
- 市值隐含不现实的市场份额；
- 市场把一次性收入资本化为永续利润；
- 估值和基本面增长严重脱节。

### 3. 市场卖出

市场结构只能辅助，不能取代基本面。可减仓的信号包括：

- 重大利好高开低走；
- 放量滞涨；
- 板块主线退潮；
- 跌破关键趋势后无法修复；
- 连续利好不能推动价格创新高。

### 4. 仓位卖出

即使逻辑未变，当单一个股因上涨超过账户15%时，也应机械降回风险上限。

## 十、我的行为纪律

1. 不因一天上涨20%就把运气当能力。
2. 不因一次成功交易放大下一笔仓位。
3. 不借贷炒股，不把生活资金转为高风险仓位。
4. 不用“国家支持、行业空间大”代替公司分析。
5. 不在重大临床、政策或诉讼结果前满仓赌博。
6. 不因看好长期逻辑忽视短期估值透支。
7. 不在板块退潮时用信仰对抗流动性。
8. 不频繁更换体系，只根据复盘证据迭代规则。
9. 每笔交易保留买入理由、失效条件和复盘记录。
10. 首要目标不是赚最快的钱，而是形成可持续复利能力。

## 十一、与量化资金共存的方法

量化资金擅长：

- 高频信号；
- 订单流；
- 统计套利；
- 板块轮动；
- 情绪强化。

个人投资者不应在其优势领域正面对抗。我的策略是：

- 研究6—24个月的产业和业绩变化；
- 用公告、财报、临床和订单验证长期逻辑；
- 利用量化造成的急跌分批买入；
- 利用情绪加速和估值透支分批卖出；
- 不追求每一段行情，只抓自己能解释的机会。

最终形成：

> 长周期认知优势 + 中周期催化跟踪 + 短周期市场确认

## 十二、体系的最终原则

### 原则一：先活下来

仓位和现金管理优先于收益目标。

### 原则二：先验证，再加仓

观点不能决定仓位，证据决定仓位。

### 原则三：区分公司价值与股票价格

好公司不一定是好股票，差公司在极端低估时也可能产生交易价值，但不能混淆两者。

### 原则四：把颠覆看成过程

持续跟踪客户、技术、商业模式、组织和竞争者反应，而不是一次性贴标签。

### 原则五：用系统替代情绪

每一笔投资都必须经过相同流程、相同评分和相同风险约束。
