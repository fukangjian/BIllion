# 《中国制造2025》投资学习包

本学习包把国务院《中国制造2025》行动纲领转化为个人投资研究材料。

## 文件目录

1. `01_中国制造2025_思维导图.md`  
   Mermaid思维导图、层级提纲和股票研究总公式。

2. `02_中国制造2025_个人读书笔记.md`  
   政策背景、战略架构、九大任务、五大工程、十大领域、批判性阅读和投资转译。

3. `03_中国制造2025_20条投资原则.md`  
   从政策到企业、从商业化到估值和风控的20条可执行原则。

4. `04_中国制造2025_A股案例验证.md`  
   北方华创、宁德时代、迈瑞医疗、中国中车、中国船舶、埃斯顿六个真实案例。

5. `05_中国制造2025_个人投资体系.md`  
   股票池、100分评分模型、估值、买卖、仓位、量化辅助、复盘和单股研究卡。

## 推荐阅读顺序

思维导图 → 读书笔记 → 20条原则 → A股案例 → 个人投资体系。

## 核心结论

> 政策负责提供长期方向，企业负责兑现竞争优势，价格负责决定收益率，仓位负责保证生存。
