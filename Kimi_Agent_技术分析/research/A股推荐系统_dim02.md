# dim02：程序化交易监管、荐股合规与LLM选股实践调研（截至2026年中）

## 程序化交易监管对个人散户的适用边界
- 《证券市场程序化交易管理规定（试行）》2024-05-15发布，**2024-10-08施行**（junhe.com/law-reviews/2715；policy.mofcom.gov.cn）。
- 沪深北交易所实施细则2025-04-03发布、**2025-07-07施行**。高频认定：单账户每秒申报+撤单≥300笔，或全日≥20000笔；高频账户需额外报告并差异化收费（新华社news.cn 2025-04-07；sse.com.cn c_20250612_10781696）。
- 报告义务**覆盖个人投资者**：凡"通过计算机程序自动生成或下达交易指令"即属程序化交易，需通过券商向交易所报告。触发门槛包括：1天内10次以上"1秒内10笔以上申报"、30日日均交易≥50只且年化换手率≥30倍、或使用自研/定制自动化软件（湘财证券告知书，2025-07-04，xcsc.com PDF）。
- 实质冲击极小：交易所试运行显示触发异常监控的主要是量化私募、券商自营，"中小个人投资者基本未发生相关情况"；低频自动化（每日数次条件单）远低于标准，主要后果仅是向券商履行报告手续（新华社，2025-04-07）。

## 荐股合规红线
- 向他人提供证券分析、预测、品种选择或买卖建议并**直接或间接收费**=证券投资咨询业务，须经证监会核准（《证券法》第120条）；无资格者最高罚500万元，情节严重构成非法经营罪。**个人自用选股系统（不向外提供建议、不收费）合法**（voc.com.cn 2024-11-15；证监会微信公众号2025-03-15）。
- 案例1：吴某平案（广东证监局，2024-11）：公众号引流+微信群荐股收费，没收255.17万元并罚款200万元。
- 案例2："金浤"案（浙江证监局，2025-12）：雪球大V公开荐股32只并反向卖出，构成操纵市场，罚没各4162.39万元、3年市场禁入（hairunlawyer.com 2026-02）。
- 即便AI生成选股结果，收费推送给他人同样涉嫌非法荐股（律师观点，2025-03）。

## LLM事件驱动选股实践（2025–2026）
- 开源项目：daily_stock_analysis（GitHub约5万star，支持DeepSeek/通义，新闻舆情+公告解读+定时推送）；go-stock（桌面端，DeepSeek新闻情绪分析）；finagent（LangGraph多Agent舆情+事件驱动）；TradingAgents中文A股改版（多智能体投研流水线）。
- 机构实践：新浪"喜娜AI"基于DeepSeek做公告AI解读（2025-03备案）；券商研报已有"事件情绪得分因子"（利好+2~利空-1）纳入多因子选股方法论。
- 坑：幻觉导致虚构个股/事件关联，需RAG先检索再精读；免费数据源限流不稳；LLM无实时性需外接新闻API；批量分析token成本需控制；超额收益普遍未经实盘验证。

## DeepSeek API 2026现状
- 当前版本：deepseek-v4-flash 与 deepseek-v4-pro，上下文1M，支持思考/非思考、Tool Calls、JSON输出。R2未单独发布，推理能力并入V3.1/V4思考模式。
- 价格：V4-Flash 输入0.02元(缓存)/1元(未缓存)、输出2元/百万token；V4-Pro 输入3元、输出6元。官网预告峰谷定价（9:00–12:00、14:00–18:00高峰2倍，生效日期待验证）（api-docs.deepseek.com/quick_start/pricing，2026-07核实）。
- 结论：V4-Flash仍是低成本批量文本分析首选；建议错峰+缓存命中优化成本。
