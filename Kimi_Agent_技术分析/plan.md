# plan.md — 职业投资自动化A股推荐系统设计方案

## 背景
用户为散户（本金约3.25万），目标3年成为基金经理；已有一套手写交易体系（七步分析框架、买入8条件、卖出风控4触发、纪律清单），实战中暴露出情绪操作、早盘时间紧张、卖单挂价失误等问题。用户具备编程能力（嵌入式、n8n、DeepSeek API、OpenClaw）。任务：输出一份"职业投资自动化A股推荐系统"设计方案文档（.docx）。

## 核心设计思想
把用户手写交易体系逐条「工程化」：
- 七步分析框架 → 事件驱动分析引擎（新闻→LLM→受益板块/个股映射）
- 买入8条件 → 可量化评分模型（≥4条触发全仓信号）
- 卖出风控 → 自动监控告警（板块破5日线/资金流出/龙头跌停/商品连跌）
- 纪律错误（追高、买后排、看分时、挂单价、WiFi）→ 系统层强制约束
- 积累案例方法论 → 自动复盘与案例库
- 用户已有工具链：n8n + DeepSeek + 钉钉 优先复用
