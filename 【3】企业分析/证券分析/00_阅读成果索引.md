## 阅读包核心结论

《证券分析》的核心并非低市盈率选股，而是建立以下决策链：

**理解证券权利 → 核验资产与负债 → 修正会计利润 → 计算正常化现金流 → 估算内在价值区间 → 要求安全边际 → 用仓位控制剩余不确定性。**

## A股案例

- 迪哲医药：使用“净现金 + 已上市产品rNPV + 在研管线概率价值 - 未来现金消耗 - 稀释”分析。
- 通源石油：使用跨周期正常化利润、扣非利润与资本开支后现金流分析。
- 中国神华：使用可持续自由现金流、股息覆盖和资源资产价值分析。

## 建议阅读顺序

先阅读思维导图，建立全局结构；再阅读完整笔记；随后使用20条原则作为检查清单；案例文件用于理解不同类型企业；最后把个人投资体系转化为日常交易规则。
