# 《巴菲特致股东信》投资学习包

本目录包含五份 Markdown 文件：

1. `01_思维导图.md`：全书核心思想的 Mermaid 与层级导图；
2. `02_个人读书笔记.md`：系统化读书笔记与A股适配；
3. `03_20条投资原则.md`：20条可执行原则、指标和违反信号；
4. `04_A股案例验证.md`：贵州茅台、美的集团、中国神华、万华化学、招商银行、海天味业、康美药业、通源石油案例；
5. `05_我的投资体系.md`：核心复利、周期价值、事件交易与现金四类资本配置体系。

## 建议使用顺序

- 第一步：阅读思维导图，建立全局框架；
- 第二步：阅读个人笔记，理解关键概念；
- 第三步：将20条原则制作成交易前检查表；
- 第四步：用A股案例理解适用边界；
- 第五步：把个人投资体系复制到自己的投资日志中执行。

## 版本说明

- 整理日期：2026-07-27
- 股东信范围：核心思想覆盖伯克希尔长期股东信，并参考官方最新披露；不同中文选本的收录年份可能不同。
- 案例数据：以交易所、上市公司年度报告和监管文件为主要依据。
- 用途：个人投资研究与训练，不构成证券投资建议。
