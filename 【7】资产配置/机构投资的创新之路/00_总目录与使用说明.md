# 《机构投资的创新之路》投资学习包

> 作者：大卫·F·史文森（David F. Swensen）  
> 原著：*Pioneering Portfolio Management*  
> 学习目标：把机构投资的资产配置、组合治理和风险控制方法，转化为个人职业投资者可执行的投资操作系统。  
> 编制日期：2026-07-27

## 二、核心结论

《机构投资的创新之路》的真正价值，不是“多买私募股权、房地产和对冲基金”，而是建立一套完整的资本管理逻辑：

- 先定义资本的使命，再讨论收益率。
- 先确定战略资产配置，再选择个股和交易时点。
- 风险不是价格波动本身，而是永久损失、流动性枯竭和目标无法完成。
- 长期投资不是长期持有任何资产，而是长期坚持正确的制度。
- 另类资产的超额收益不来自“另类”二字，而来自市场低效、管理人能力和长期资本优势。
- 个人投资者不能复制耶鲁的资源禀赋，但可以复制其纪律、治理和组合思维。

## 三、对个人投资者最重要的迁移

耶鲁捐赠基金具有永久期限、稳定支出规则、专业团队、顶级外部管理人和私募市场准入。个人投资者不具备完全相同的条件，因此应当采用“原则迁移”，而不是“配置比例复制”。

| 耶鲁模式 | 个人投资者迁移方式 |
|---|---|
| 永续基金 | 把核心本金视为长期生产资料，不轻易消耗 |
| 年度支出政策 | 设置生活支出账户与投资账户隔离 |
| 战略资产配置 | 预先规定现金、核心权益、主动权益和高风险机会的上限 |
| 另类资产 | 用能力圈内的低效市场、冷门行业和特殊情形替代盲目追逐私募产品 |
| 外部管理人选择 | 选择基金经理、研究信息源和合作伙伴时重视诚信、能力与利益一致 |
| 定期再平衡 | 利用估值和仓位偏离进行机械化逆向调整 |
| 投资委员会治理 | 使用投资政策书、检查清单、交易日志和月度复盘约束自己 |

## 四、资料口径与限制

本学习包依据原著的公开目录、出版社资料、耶鲁大学投资办公室公开材料以及上市公司法定披露整理，不替代逐页阅读原著。案例部分截至2026年7月27日，迪哲医药与阿斯利康的授权交易仍存在股东会审批、反垄断审批和交割条件等不确定性，因此不能把全部潜在里程碑款视为确定性资产。

## 五、建议阅读顺序

先读思维导图，建立全书结构；再读读书笔记；随后把20条原则改写成自己的投资政策；最后用迪哲医药案例和个人投资体系进行实战演练。
