# A股案例验证：迪哲医药（688192）

> 用户示例中的“迪泽医药”按上市公司正式名称更正为“迪哲医药”。  
> 数据口径截至：2026-07-27。  
> 本文用于验证《机构投资的创新之路》的组合框架，不构成买卖建议。

## 一、为什么选择迪哲医药作为案例

迪哲医药是一家处于商业化阶段但尚未实现持续盈利的创新药公司。其价值由已上市产品、临床管线、监管审批、商业化能力、授权交易和资金消耗共同决定，具有以下典型特征：

- 现金流与会计利润暂时不稳定；
- 单个临床或监管事件可能显著改变价值；
- 估值高度依赖远期假设；
- 信息专业性高，普通投资者容易高估理解能力；
- 股价波动和基本面价值可能在短期严重偏离；
- 适合作为“高不确定性、正偏度资产”的组合管理案例。

这类公司不能只用市盈率分析，更不能只看技术走势。它要求投资者同时处理科学、商业、概率、估值和仓位问题。

## 二、公开事实快照

### 1. 经营进展

公司2025年实现营业收入约8.01亿元，同比增长122.60%；归属于母公司所有者的净亏损约7.63亿元，研发投入约8.56亿元。两款商业化产品舒沃哲和高瑞哲进入国家医保后，销售规模明显增长，但公司仍处于高研发投入阶段。

2026年半年度业绩预告显示，公司预计实现营业收入约5.22亿元，同比增长约47.04%；预计归母净亏损约2.10亿元，亏损同比收窄约44.35%。该数据表明商业化放量和减亏趋势存在，但尚不能证明公司已进入稳定自由现金流阶段。

### 2. 产品与临床进展

- 舒沃哲（舒沃替尼）已在中国和美国获批用于特定EGFR exon20ins非小细胞肺癌患者。
- 舒沃哲一线治疗相关适应症已推进至全球关键临床和上市申请阶段。
- 高瑞哲（戈利昔替尼）已在中国获批上市。
- 公司还有birelentinib（DZD8586）、DZD6008等在研管线，未来价值取决于临床、审批和商业化结果。

### 3. 2026年7月授权交易

公司公告与阿斯利康签署舒沃哲全球独家开发、商业化许可协议。协议包括：

- 一次性、不可返还首付款6亿美元；
- 最高4亿美元临床开发里程碑；
- 最高5亿美元销售里程碑；
- 全球销售额最高到低双位数的阶梯式特许权使用费。

但该交易截至本文日期仍需股东会批准，并需满足交割条件及取得相关反垄断审批。里程碑和特许权使用费也取决于临床、监管和销售目标，不能按公告上限全额计入确定价值。

## 三、用史文森框架分析

## 1. 先看资本使命：它适合什么资金

迪哲医药不适合作为承担生活费、应急支出或短期购房需求的资金载体。其价值兑现依赖多年临床和商业化过程，短期可能因审批、竞争、交易进展和市场风险偏好大幅波动。

**结论：** 只能使用长期、无刚性用途的风险资本；不能使用贷款和短期周转资金。

## 2. 再看资产类别：它不是传统稳定成长股

从经济属性看，迪哲医药更接近公开市场中的“风险投资项目组合”：

- 已上市产品提供部分现实收入；
- 核心价值仍由未来适应症和在研管线决定；
- 收益分布右偏，成功时可能大幅增值，失败时可能显著减值；
- 单个项目之间并非完全独立，研发平台、团队和资金状况形成共同风险。

因此，投资者不能用消费、银行或成熟制造业的估值和仓位方法处理它。

## 3. 市场是否低效

创新药市场存在一定低效：

- 临床数据解读门槛高；
- 适应症人群、竞争格局和商业化渗透率容易被误判；
- 市场可能在临床会议、授权交易和政策事件后过度反应；
- 卖方模型对远期峰值销售和成功概率非常敏感。

但“市场低效”不代表个人投资者自动拥有优势。若不能独立阅读临床终点、对照组设计、安全性、竞争药物和监管路径，所谓低效反而会放大信息劣势。

**结论：** 只有具备医药研究能力或可靠专家网络时，才适合主动重仓；否则只能作为受限小仓位。

## 4. 资产配置而非单股判断

即使看好迪哲医药，也必须先回答它在组合中承担什么功能：

- 不是现金流资产；
- 不是防御资产；
- 不是低波动核心资产；
- 是高不确定性、高波动、潜在高收益的卫星资产。

它应占用“创新成长/事件驱动风险预算”，而不是挤占生活现金、核心指数或防御资产份额。

## 四、价值拆分：避免把故事当估值

迪哲医药的股权价值可拆为：

```text
股权价值
= 现有净现金及可确认交易对价
+ 舒沃哲未来特许权使用费的风险调整现值
+ 高瑞哲商业化价值
+ DZD8586风险调整现值
+ DZD6008风险调整现值
+ 其他早期管线与平台期权价值
- 未来研发与管理费用现值
- 税费、稀释和执行风险折价
```

### 1. 不能直接相加的项目

- 最高4亿美元临床里程碑不是应收账款；
- 最高5亿美元销售里程碑不是已实现收入；
- 低双位数特许权费需要结合实际销售额、期限、成本和税费；
- 首付款是否以及何时确认，要以交易生效、交割和会计处理为准；
- 账面现金需要扣除未来研发和商业化消耗。

### 2. 建议使用概率加权

对每条管线分别估计：

- 目标患者人数；
- 渗透率；
- 年治疗费用；
- 峰值销售；
- 达峰时间；
- 专利和竞争期限；
- 临床成功概率；
- 监管批准概率；
- 商业化折扣；
- 折现率。

由于输入误差极大，估值应输出区间，而不是精确到个位数的目标价。

## 五、三情景分析

## 悲观情景

- 授权交易审批或交割延迟；
- 一线适应症审批或商业化进度低于预期；
- 竞争药物改善标准治疗；
- 后续管线临床结果不佳；
- 研发费用继续高企；
- 市场风险偏好下降，创新药估值整体压缩。

**组合含义：** 即使公司不会出现立即偿付危机，股价仍可能大幅回撤。仓位必须保证在悲观情景下不破坏账户生存。

## 基准情景

- 授权交易顺利完成；
- 首付款增强现金储备并降低融资压力；
- 舒沃哲一线适应症取得正常进展；
- 高瑞哲维持增长；
- 核心管线按计划推进，但没有全部成功；
- 公司逐步从自主营销为主转向“研发平台+合作商业化”模式。

**组合含义：** 价值重估来自现金安全垫、全球商业化能力和风险调整后的管线价值，而不是单纯收入倍数提升。

## 乐观情景

- 舒沃哲一线适应症在主要市场获批并快速放量；
- 全球销售显著超过基准预期；
- DZD8586、DZD6008至少一项成为重要新增价值来源；
- 公司持续完成高质量对外授权；
- 研发平台获得资本市场更高可信度。

**组合含义：** 收益具有明显右偏特征，但不能因乐观上限巨大而忽略失败概率。

## 六、20条原则的案例验证

| 原则 | 迪哲医药验证 |
|---|---|
| 资本使命 | 不能用短期生活资金持有多年研发风险 |
| 实际购买力 | 高波动收益必须覆盖通胀、机会成本和失败项目损失 |
| 资产配置优先 | 单股再优秀也只能占用有限风险预算 |
| 期限匹配 | 管线价值兑现周期长，应使用长期资本 |
| 流动性保险 | 现金使投资者不必在临床或市场冲击时被迫卖出 |
| 永久损失 | 临床失败、竞争替代和高估值压缩均可能造成永久损失 |
| 风险因子分散 | 同时持有多只创新药并不一定分散，可能共同暴露于政策和风险偏好 |
| 主动优势 | 不懂临床设计时不应重仓 |
| 谨慎择时 | 不能只根据会议日期或公告日期进行全仓押注 |
| 再平衡 | 大涨后若仓位超限，应按规则减仓而不是让胜利冲昏头脑 |
| 加仓前复核 | 下跌后必须区分情绪回撤与基本面破坏 |
| 杠杆约束 | 创新药高波动与融资杠杆不兼容 |
| 复杂性 | 专业术语和管线数量不能替代现金流分析 |
| 管理人品格 | 需关注管理层信息披露、研发决策和资本配置纪律 |
| 费用 | 研发支出是获得未来价值的必要成本，也可能成为长期消耗 |
| 估值起点 | 好药物不等于任何价格都值得买 |
| 催化剂 | 授权协议是重要催化，但仍有审批和执行条件 |
| 完整周期 | 需跨临床、审批、商业化周期评价，而非看几周走势 |
| 事前记录 | 在公告前后分别记录预期，避免事后解释 |
| 组织能力 | 医药数据库、论文阅读、专家访谈和跟踪表决定研究质量 |

## 七、仓位和交易规则示例

以下是风险控制示例，不是固定建议：

### 1. 仓位层级

- 初始观察仓：总资产的1%—2%；
- 研究确认仓：2%—3%；
- 高确信上限：通常不超过5%；
- 若账户缺少行业分散，创新药板块总仓位应另设上限。

### 2. 允许加仓的条件

- 临床或审批概率出现可验证的正向变化；
- 商业化数据高于原假设；
- 交易正式生效并改善现金安全垫；
- 股价下跌但价值假设未破坏，且组合风险仍在上限内。

### 3. 必须减仓或退出的条件

- 核心临床终点失败或安全性显著恶化；
- 竞争格局使峰值销售假设明显下降；
- 授权交易未能生效且融资压力重新上升；
- 管理层治理、信息披露或资本配置出现重大问题；
- 股价上涨使仓位超过风险预算或估值已透支乐观情景。

### 4. 不构成卖出理由的情况

- 单日波动；
- 没有基本面信息的市场传闻；
- 短期未跑赢医药指数；
- 仅因为股价跌破个人成本价。

---

## 八、案例结论

迪哲医药可以是具有长期创新价值和右偏收益特征的标的，但它不应成为个人投资组合的“生存核心”。史文森框架要求投资者把它放入正确的资产类别、使用正确期限的资金、给予受限仓位，并以概率加权估值和事件跟踪管理风险。

**真正的机构化处理方式不是判断“迪哲医药一定涨或一定跌”，而是确保无论哪种情景发生，组合都能继续运作，并在新信息出现时有能力重新配置资本。**
