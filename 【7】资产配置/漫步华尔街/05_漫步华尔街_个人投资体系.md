# 基于《漫步华尔街》的个人投资体系

> 目标：以100万元本金为起点，在5年内完成从嵌入式软件架构师到职业投资者的能力验证。体系不追求纯被动，也不允许未经证明的激进主动，而采用“指数核心 + 主动卫星 + 事件战术 + 基准审计”。

## 一、体系总纲

我的投资系统升级为：

```text
长期财富 = 市场Beta + 可验证Alpha - 成本 - 行为错误 - 致命回撤
```

对应决策链：

```text
资产配置决定生存
→ 指数核心获取市场回报
→ 产业研究寻找有限主动机会
→ 估值与预期差决定赔率
→ 资金结构决定执行节奏
→ 仓位上限控制未知风险
→ 基准审计验证能力
→ 复盘推动系统迭代
```

## 二、我的优势与主要风险

### 2.1 可利用的优势

1. **软件架构思维**：擅长模块化、接口、状态机、异常处理和版本迭代。
2. **技术产业理解**：能够研究AI、半导体、物联网、医疗设备和边缘计算。
3. **持续学习能力**：已建立系统化读书和AI复盘流程。
4. **小资金容量优势**：100万元可进入机构容量受限的中小盘机会。
5. **无强制排名压力**：可以等待，不必每天交易。

### 2.2 必须约束的风险

1. 容易被热点、战争和重大公告刺激；
2. 单次盈利后容易提高自信；
3. 有从技术岗位快速转向资本路线的收益焦虑；
4. 容易将完整产业逻辑误当作短期价格必然；
5. 可能用高集中度加速实现财务自由，导致永久损失。

## 三、四账户资本架构

### 3.1 初始配置

| 账户 | 初始比例 | 金额（按100万元） | 目标 |
|---|---:|---:|---|
| 核心指数账户 | 50% | 50万元 | 获得市场长期回报，作为职业转型安全底座 |
| 主动产业账户 | 30% | 30万元 | 验证创新药、AI、半导体、资源等研究优势 |
| 事件战术账户 | 5% | 5万元 | 训练政策、BD、临床、地缘冲突交易 |
| 现金与低波动账户 | 15% | 15万元 | 应急、再平衡和等待机会 |

允许区间：

| 账户 | 下限 | 上限 |
|---|---:|---:|
| 核心指数 | 40% | 60% |
| 主动产业 | 25% | 40% |
| 事件战术 | 0% | 10% |
| 现金与低波动 | 10% | 25% |

### 3.2 为什么不是全部主动

在尚未证明Alpha前，全部主动等于用全部本金参加能力考试。一旦判断错误，职业投资计划和生活安全同时受损。核心指数账户使我即使主动研究暂时失败，也能保留市场长期回报和继续学习的资本。

## 四、基准体系

### 4.1 组合总基准

选择一个可复制、低成本的A股宽基作为主基准，并保持至少三年不随意更换。可选范围：沪深300、中证A500或能够代表实际投资范围的宽基指数。

### 4.2 分账户基准

| 账户 | 比较基准 |
|---|---|
| 核心指数账户 | 所跟踪宽基指数全收益表现 |
| 创新药主动仓 | 对应医药或创新药行业指数 |
| AI/半导体主动仓 | 对应科技或半导体行业指数 |
| 油气资源仓 | 对应能源或油气行业指数 |
| 现金账户 | 低风险现金管理收益率 |

### 4.3 不能只看绝对收益

必须同时记录：

```text
主动超额收益 = 主动账户收益 - 对应基准收益
风险调整超额 = 主动超额收益 / 主动账户波动或回撤
```

若主动仓赚20%，但行业指数同期涨30%，这不是成功选股。

## 五、主动投资五维评分模型

每个标的满分100分，低于70分不得建立正式仓位。

| 维度 | 权重 | 核心问题 |
|---|---:|---|
| 产业与政策 | 20 | 是否处于长期增长或边际改善阶段？ |
| 公司质量 | 20 | 产品、竞争壁垒、管理、财务和现金流如何？ |
| 估值与隐含预期 | 25 | 当前价格已经计入多少成功？下行空间多大？ |
| 催化与预期差 | 20 | 哪个可验证事件会改变市场定价？ |
| 资金与交易结构 | 15 | 是否有量价确认、承接和板块联动？ |

### 评分对应动作

| 得分 | 动作 |
|---|---|
| 0—59 | 排除 |
| 60—69 | 观察，不买 |
| 70—79 | 2%—5%研究仓 |
| 80—89 | 5%—10%标准仓 |
| 90—100 | 10%—15%核心主动仓，仍不得突破单票上限 |

## 六、估值与预期差系统

### 6.1 通用估值

成熟公司：

```text
企业价值 = 正常化自由现金流 × 合理倍数
```

周期公司：

```text
企业价值 = 跨周期正常化利润 + 资源或资产价值 - 净负债
```

创新药：

```text
企业价值 = 净现金
+ 已上市产品风险调整净现值
+ 在研管线概率净现值
+ 平台期权价值
- 未来研发与商业化投入
- 稀释折价
```

### 6.2 必须输出的三种情景

每次买入前必须填写：

| 情景 | 概率 | 估值 | 相对现价空间 |
|---|---:|---:|---:|
| 悲观 |  |  |  |
| 基准 |  |  |  |
| 乐观 |  |  |  |

概率加权价值：

```text
概率加权价值 = 悲观价值×概率 + 基准价值×概率 + 乐观价值×概率
```

只有当概率加权价值相对现价具有足够安全边际，且悲观情景损失可承受，才允许买入。

## 七、仓位与风险预算

### 7.1 硬性上限

| 风险项 | 上限 |
|---|---:|
| 单一股票 | 总资产15% |
| 单一创新药公司 | 总资产10%—12% |
| 单一事件交易 | 总资产5%—8% |
| 单一行业 | 总资产30% |
| 高相关成长行业合计 | 总资产45% |
| 融资与借贷 | 0% |
| 裸卖期权和无限损失策略 | 禁止 |

### 7.2 单笔风险

```text
单笔最大计划亏损 ≤ 总资产1%
```

若总资产100万元，单笔计划亏损上限约1万元。假设止损距离为8%，最大仓位约为：

```text
1万元 ÷ 8% = 12.5万元
```

这与单票15%上限相互约束，取更小值。

### 7.3 组合回撤控制

| 状态 | 动作 |
|---|---|
| 单周回撤超过4% | 停止新增事件仓，复核高相关持仓 |
| 单月回撤超过8% | 主动账户仓位降低三分之一 |
| 组合回撤超过12% | 主动账户降至总资产20%以内 |
| 组合回撤超过15% | 停止实盘扩张，进入系统审计 |
| 连续3笔违反规则 | 暂停交易5个交易日 |

## 八、买入系统

### 8.1 四个必要条件

1. 研究逻辑可证伪；
2. 当前价格未完全计入基准情景；
3. 风险收益比至少2:1；
4. 仓位和退出规则已写入交易计划。

### 8.2 三类买点

#### A. 低关注研究买点

- 基本面边际改善；
- 市场关注较低；
- 估值处于悲观定价；
- 没有明显资金拥挤。

仓位：2%—5%。

#### B. 事件确认买点

- 临床、审批、订单、BD或业绩落地；
- 新增价值大于市值增量；
- 板块有扩散，个股有承接；
- 不在连续加速后追高。

仓位：首次不超过5%，验证后再加。

#### C. 回调再平衡买点

- 逻辑未破；
- 估值重新出现安全边际；
- 回调不是行业系统性恶化；
- 原仓位未超过上限。

## 九、卖出系统

### 9.1 逻辑卖出

- 核心假设被证伪；
- 管线失败、订单取消、政策逆转；
- 盈利质量或现金流恶化；
- 竞争格局显著恶化；
- 原预期差已经完全兑现。

### 9.2 估值卖出

- 市价达到乐观情景价值；
- 市值增量明显超过基本面新增价值；
- 市场使用“无限空间”替代可计算假设；
- 仓位因上涨超过组合上限。

### 9.3 资金与时间卖出

- 放量滞涨且板块退潮；
- 事件利好落地但价格无法维持；
- 预定时间内关键指标未实现；
- 存在更高赔率机会，且原标的没有税费或流动性障碍。

## 十、核心指数账户规则

1. 不用短线新闻择时核心仓；
2. 通过工资或新增现金持续投入；
3. 每季度检查一次；
4. 偏离目标配置5个百分点以上才再平衡；
5. 市场大跌时不因恐慌全部退出；
6. 不因主动仓短期胜出而侵占核心仓；
7. 核心仓只因人生资金需求、长期资产配置变化或指数规则变化而调整。

## 十一、主动能力升级门槛

### 11.1 从30%主动仓升至40%

必须同时满足：

- 连续24个月扣费后跑赢对应基准；
- 年化超额收益不少于5个百分点；
- 最大回撤不高于基准5个百分点以上；
- 至少50笔完整交易；
- 收益来源不集中于一笔交易；
- 没有融资、借贷或违反仓位规则。

### 11.2 主动仓降级条件

- 滚动12个月落后基准超过8个百分点；
- 回撤显著高于基准；
- 频繁违反交易纪律；
- 收益主要来自市场风格Beta而非选股；
- 研究时间不足或工作影响执行质量。

降级动作：将主动仓减少10个百分点，转入核心指数或现金，完成系统复盘后再申请恢复。

## 十二、职业投资者五年路线

### 第1年：建立基准和数据

- 完成四账户分离；
- 建立交易、阅读和错误数据库；
- 所有交易有事前计划；
- 每月完成组合归因；
- 不追求离职，不追求翻倍。

### 第2年：验证主动优势

- 累积至少50笔完整样本；
- 检验创新药、科技和事件系统；
- 识别真正有优势的1—2类策略；
- 淘汰无效指标和高成本交易。

### 第3年：形成专长

- 将研究聚焦在少数产业；
- 建立行业数据库、估值模型和催化日历；
- 主动仓是否扩大由数据决定；
- 开始计算投资收入对生活支出的覆盖率。

### 第4年：压力测试

- 检验熊市、震荡和风格逆转表现；
- 预留至少24个月生活费用；
- 模拟工资收入消失后的资产配置；
- 检验系统是否依赖持续牛市。

### 第5年：职业化决策

只有同时满足以下条件才考虑职业转型：

- 至少3年可核验实盘记录；
- 主动体系长期跑赢基准且风险可控；
- 投资体系不依赖单一行情；
- 生活备用金与投资本金分离；
- 预计投资现金流能够覆盖主要支出；
- 即使未来两年表现低迷，也不会被迫退出市场。

## 十三、我的投资委员会否决权

任何一项为“是”，交易自动否决：

```text
[ ] 是否依赖借贷或杠杆？
[ ] 是否因为害怕错过而买入？
[ ] 是否无法写出悲观情景？
[ ] 是否无法找到合适基准？
[ ] 是否单票或行业超限？
[ ] 是否只凭技术图形或小作文？
[ ] 是否把未触发里程碑当作确定收入？
[ ] 是否在公告后大涨时临时改变估值？
[ ] 是否没有明确的逻辑失效条件？
[ ] 是否会因本次亏损影响生活和职业计划？
```

## 十四、最终投资信条

1. 我不需要预测每一天，只需要长期留在正确的概率一侧。
2. 指数不是对主动投资的否定，而是检验主动能力的基准。
3. 我只用有限资本证明Alpha，不用全部本金满足自尊。
4. 好公司、好行业和好故事，必须通过好价格连接到回报。
5. 我允许错，但不允许单一错误破坏五年计划。
6. 我把投资当作可测试、可监控、可回滚的软件系统。
7. 最终目标不是看起来像职业投资者，而是拥有可持续的职业投资结果。
