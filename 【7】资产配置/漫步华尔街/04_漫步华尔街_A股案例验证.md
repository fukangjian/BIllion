# 《漫步华尔街》A股真实案例验证

> 目标：验证书中思想在A股是否成立，而不是事后挑选最优买卖点。案例包括迪哲医药、A股主动基金与指数、中国石油上市泡沫，以及个人通源石油交易复盘。

## 案例一：迪哲医药——重大基本面突破与快速重新定价

### 1. 基本事实

迪哲医药（688192）采用科创板第五套标准上市。2025年年度报告显示：

- 2025年销售收入8.01亿元，同比增长122.60%；
- 两款商业化产品进入医保后销售放量；
- 公司仍未盈利并存在累计未弥补亏损；
- 2025年研发投入8.56亿元；
- 再融资后资产负债率由期初88.36%降至期末56.85%。

2026年7月14日，公司宣布与阿斯利康签署舒沃哲全球独家许可协议：

- 首付款6亿美元；
- 临床开发和销售里程碑付款合计最高9亿美元；
- 另有全球销售额分级特许权使用费；
- 交易完成仍需满足交割和监管条件；
- 里程碑及特许权使用费存在不确定性。

消息公布后，公司股价当日出现20%涨停，体现信息快速进入价格。

### 2. 对应本书观点

#### 观点A：公开信息会迅速反映到价格中

公告前持有者获得的是“事件被市场确认前”的风险溢价；公告后追涨者面对的是已重新定价的价格。重大利好并不自动意味着次日以后仍有同等赔率。

#### 观点B：好公司不等于任何价格都值得买

许可交易改善了现金流和全球商业化能力，但估值仍需拆分：

```text
确定价值：首付款的税后净现值
+ 概率价值：里程碑款 × 触发概率
+ 特许权价值：全球销售额 × 分成率 × 利润率 × 折现
+ 其他管线价值
- 持续研发费用
- 商业化费用
- 税费与潜在稀释
```

不能把15亿美元全部当作当期确定收入，更不能简单把美元金额直接加到市值上。

#### 观点C：单一公司风险必须用仓位控制

即使舒沃哲取得重大进展，仍存在：

- 审批和适应症扩展风险；
- 海外销售放量风险；
- 竞争药物风险；
- 交易完成条件风险；
- 其他管线研发失败风险；
- 估值透支风险。

因此，迪哲医药适合成为主动研究仓，不适合承担全部职业转型本金。

### 3. 事前、事中、事后的正确动作

| 阶段 | 正确研究重点 | 仓位建议 |
|---|---|---:|
| 临床与BD预期尚未确认 | 临床质量、差异化、现金消耗、潜在合作价值 | 3%—8%研究仓 |
| 关键数据或BD落地 | 重新计算确定价值和隐含预期 | 不因涨停自动加仓 |
| 价格大幅重估后 | 比较新增价值与市值增量 | 高估则减仓或等待 |
| 后续审批与销售验证 | 跟踪实际现金流和触发条件 | 按证据调整，而非按情绪 |

### 4. 案例结论

迪哲医药并未证明“基本面分析无效”，反而证明：

```text
基本面研究可以识别潜在价值，
但事件发生时间难预测，
信息落地后价格反应很快，
最终仍需估值和仓位管理。
```

## 案例二：A股主动基金与指数——主动管理有机会，但持续性不足

S&P Dow Jones Indices的SPIVA Asia Ex-Japan 2025报告以S&P China A 300为中国大盘主动基金比较基准。结果显示：

| 期限 | 中国大盘主动基金跑输基准比例 |
|---|---:|
| 2025年单年 | 43.3% |
| 3年 | 65.6% |
| 5年 | 52.8% |
| 风险调整后3年 | 66.6% |
| 风险调整后5年 | 52.8% |

### 1. 如何解释

2025年中国大盘主动基金多数跑赢基准，说明A股并非任何时期都完全有利于被动投资；但期限延长后，多数基金仍难以持续跑赢，且风险调整后的结果更弱。

### 2. 对我的启示

- 不能用“美国主动基金多数失败”直接推断A股主动投资毫无价值；
- 也不能用2025年主动基金胜出推断未来继续胜出；
- 主动投资要比较长期、扣费后、风险调整后的结果；
- 指数应成为默认基准，而不是意识形态选择。

### 3. 职业投资者验证标准

主动账户若满足以下条件，才可扩大仓位：

```text
滚动24个月扣费后年化收益 > 对应基准5个百分点
最大回撤不高于基准5个百分点以上
至少50笔完整交易
收益不依赖单一股票或单一事件
在上涨、下跌和震荡环境中均有记录
```

## 案例三：中国石油2007年上市——“伟大公司”和“空中楼阁价格”

中国石油A股发行价为16.70元，2007年11月5日上市首日开盘约48.62元，收盘43.96元。首日价格相对发行价大幅上涨，并伴随“全球市值第一”等强烈叙事。

### 1. 对应本书观点

这是典型的“坚实基础与空中楼阁分离”：

- 公司拥有重要资源和国家战略地位；
- 但上市首日价格包含了极高增长、油价和情绪预期；
- 投资者购买的不只是企业现金流，还购买了市场亢奋；
- 再优秀的资产，在极端价格下也可能带来长期低回报。

### 2. 可执行教训

当出现以下组合时，应主动降低仓位：

```text
全民关注
+ 新时代叙事
+ 首日或短期巨幅上涨
+ 估值显著脱离历史和同业
+ 买入理由主要是“还会继续涨”
```

### 3. 案例结论

估值不是预测短期顶部的工具，而是决定长期回报起点的工具。

## 案例四：2026年通源石油交易——正确结果不等于已经证明能力

根据个人交易记录，我在2026年7月基于以下信息买入通源石油：

- 美伊冲突与海峡封锁风险；
- 国际油价走强；
- A股科技高位分化，资金寻找新方向；
- 油气板块多股启动；
- 通源石油低位放量、分时横盘并出现资金试盘特征。

买入后短期盈利约20%。

### 1. 这笔交易做对了什么

- 宏观事件、商品价格、板块联动和个股结构形成共振；
- 不是只凭单条消息追涨；
- 有明确持有逻辑和战争进程退出思路；
- 选择了资金开始关注的方向。

### 2. 仍未证明什么

- 未证明能够持续预测战争进程；
- 未证明低位放量模式长期有效；
- 未证明20%收益全部来自能力；
- 未证明同类交易在错误时不会造成更大亏损；
- 未证明重仓此类事件交易优于长期指数。

### 3. 正确的统计方法

以后将同类交易归入“地缘冲突—资源股事件系统”，累计记录：

| 指标 | 记录内容 |
|---|---|
| 样本数 | 至少20笔再初步判断 |
| 胜率 | 盈利交易比例 |
| 平均盈利 | 盈利单平均收益 |
| 平均亏损 | 亏损单平均损失 |
| 最大不利变动 | 买入后最深回撤 |
| 持有期 | 事件影响持续时间 |
| 板块确认 | 龙头、涨停家数、成交额 |
| 基准收益 | 同期油气指数或宽基表现 |

期望值：

```text
交易期望 = 胜率 × 平均盈利 - 败率 × 平均亏损 - 交易成本
```

### 4. 案例结论

一次成功交易只能进入数据库，不能直接升级为投资原则。只有重复样本和基准比较，才能把“故事”变成“系统”。

# 四个案例的统一结论

| 本书命题 | A股验证 |
|---|---|
| 市场会出现泡沫 | 中国石油上市首日体现叙事和价格脱离 |
| 公共信息快速计价 | 迪哲医药重大许可公告后快速涨停 |
| 主动管理难持续胜出 | 中国大盘主动基金长期跑输比例上升 |
| 单次成功不能证明能力 | 通源石油盈利需要纳入同类样本审计 |
| 分散和仓位非常重要 | 创新药、资源股均存在单一事件和行业风险 |
| 指数是可靠基准 | 主动账户必须与可复制基准比较 |

# 最终案例判断

《漫步华尔街》在A股不是“全盘正确”或“完全失效”。更准确的结论是：

```text
A股存在更多结构性错价和主动机会，
但也存在更强的叙事、轮动和行为偏差；
因此个人投资者更需要基准、分散、低成本和严格的能力验证。
```
