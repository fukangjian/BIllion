# 系统思考投资检查清单

## 一、研究启动

- [ ] 分析周期明确：短线 / 波段 / 中长期
- [ ] 账户归属明确：核心复利 / 产业趋势 / 事件交易
- [ ] 收益来源明确：业绩增长 / 估值修复 / 周期反转 / 事件催化
- [ ] 一手资料已阅读
- [ ] 事实与观点已分开

## 二、系统结构

- [ ] 已定义系统边界
- [ ] 已列出5—10个关键变量
- [ ] 已画出完整因果链
- [ ] 至少两条增强回路R
- [ ] 至少两条调节回路B
- [ ] 已识别关键时间延迟
- [ ] 已识别增长极限
- [ ] 已识别系统杠杆点
- [ ] 已识别最危险负反馈

## 三、心智模式

- [ ] 我的核心假设已经写出
- [ ] 已列出至少三个反方证据
- [ ] 已提出替代解释
- [ ] 没有把价格行为直接当作基本面事实
- [ ] 没有因持仓而改变证据标准
- [ ] 明确什么事实出现时承认错误

## 四、估值与预期

- [ ] 市场共识明确
- [ ] 预期差明确
- [ ] 当前价格隐含的成功率已估计
- [ ] 牛、基、熊三种情景已建立
- [ ] 熊市损失可以承受
- [ ] 上行空间大于下行风险
- [ ] 没有把最高里程碑、最大市场空间或远期利润直接当作当前价值

## 五、买入

- [ ] 买入条件已触发
- [ ] 初始仓位与不确定性匹配
- [ ] 止损或证伪条件明确
- [ ] 加仓条件明确
- [ ] 催化时间与持有周期匹配
- [ ] 流动性足够
- [ ] 组合相关性可接受
- [ ] 情绪稳定，不是因为害怕错过

## 六、持仓监控

### 企业系统

- [ ] 产品、订单、价格或临床数据是否变化
- [ ] 收入、利润、现金流是否按预期演化
- [ ] 竞争格局是否变化
- [ ] 资本配置是否合理
- [ ] 增长瓶颈是否提前出现

### 股票系统

- [ ] 板块相对强弱
- [ ] 成交量、换手和承接
- [ ] 事件兑现后的价格反应
- [ ] 估值是否透支
- [ ] 交易是否拥挤

### 自身系统

- [ ] 是否偏离原计划
- [ ] 是否因盈亏改变判断标准
- [ ] 是否出现补仓冲动
- [ ] 是否把短线交易拖成长线
- [ ] 是否需要降仓而非继续解释

## 七、卖出

- [ ] 核心逻辑被证伪
- [ ] 增强回路逆转
- [ ] 调节回路显著增强
- [ ] 增长极限提前到来
- [ ] 估值已透支牛市情景
- [ ] 催化兑现但承接失败
- [ ] 板块进入退潮
- [ ] 组合风险过高
- [ ] 出现更高赔率机会

## 九、一票否决

出现以下任一情况，停止交易：

- [ ] 无法解释核心逻辑
- [ ] 无法定义最大损失
- [ ] 无证伪条件
- [ ] 使用借贷或不可承受资金
- [ ] 情绪失控
- [ ] 试图快速翻本
- [ ] 因害怕错过而追入
- [ ] 交易计划在买入后才编写

## 十、最终口令

> 看系统，不看单点；看证据，不看愿望；看赔率，不看热闹；用仓位控制错误，用复盘升级系统。
