    Invest 控制台 · 使用说明 
    
    
    定位：系统负责筛选与计算，人负责决策与下单。清单是候选与参数，不是自动买入指令。
    

    
    🚀 快速上手四步
    
    
      
      
    1. 一键盘前（顶栏右侧按钮）：抓取数据 → 扫描 → 持仓监控 → 信号结算 → 日报，全程 1-3 分钟；跑完页面自动刷新。
      2. 
      
    2. 看「明日操作计划」：🐉 龙头候选（系统判定+置信度）置顶，📈 趋势候选在后；先看「本期系统认定龙头」横幅和「明日板块聚焦」。
      3. 
      
    3. 执行：候选行尾「建仓」按钮一键落库（自动过合规闸门）；持仓在「快捷操作」页签里加仓/卖出/卖点检查。
      4. 
      
    4. 复盘：周报/月报自动写 vault（【10】实盘记录/），「报告与复盘」区在线看。
      5. 
    
    

    
    📖 各区块怎么读
    
    
      
      
    • 市场状态 A/B/C/D：决定总仓位上限与趋势仓许可；D 状态闸门直接拒绝新开趋势仓，C 状态建议风险减半。
      • 
      
    • 等级（S/A/B/C）：量化五维评分（身位/梯队/强度/逻辑/情绪），S≥80 分。
      • 
      
    • 系统判定（真龙头/疑似/跟风/伪龙头 + 置信度）：Kimi 推理模型综合评分、涨停归因、证据链后的判定；悬浮徽章可见完整判定理由与风险。
      • 
      
    • 9:25 竞价核对清单：竞价定去留——高开 3-5% 放量执行、一字不追、低开剔除（龙头候选/竞价清单/关键事项均只列前 5 只，完整名单见扫描报告）。
      • 
      
    • 🃏 二板观察池：《二板打法》首板→二板——首板硬条件（首封时间/封单力度/换手/市值/股价/前5日涨幅）全过 + 软评分 ≥6 分入池；表中「次日涨停价」是 S 级竞价挂单参考，「硬止损」为 -10%；竞价等级与风控铁律在卡片底部，人工执行。
      • 
      
    • ⏰ 9:25 竞价结果：竞价撮合后（9:26 定时自动跑，或点「刷新竞价」手动跑）自动判定——二板按高开幅度×竞昨比×板块共振分 S/A/B/C 级，龙头按 3-7% 放量执行/一字不追/低开剔除，持仓低开 ≤-2% 或竞价破止损出红色警报；S/A 级附 9:20→9:25 抢筹/撤单走向。
      • 
      
    • 📅 未来 30 天关键事项：财报预约/解禁 + 板块政策会议事件；🔍 个股证据链：Top 候选的引爆点与正反证据（点行展开）。
      • 
      
    • 持仓行动：止损/退出/无止损/移动止损建议逐条列出，直接点「补/改止损」「卖出」。
      • 
      
    • force 勾选：高级违规（如单笔风险超限）强制建仓，备注自动留痕——正常情况不要勾。
      • 
    
    

    
    ❓ 常见问题
    
    
      
      
    • 龙头组空了/有红色横幅：Kimi 推理未启用或失败（检查 KIMI_API_KEY），系统降级为纯量化评分排序，横幅会明说原因。
      • 
      
    • 闸门预检 ⛔：命中硬性风控（禁买前缀/总热度超限/D 状态禁开仓等），按提示降风险或放弃。
      • 
      
    • 数据日期不是今天：行情取自本地 market.db 最新收盘（非盘中实时），盘前使用足够。
      • 
    
    

    
    风险提示：本系统是个人风险管理框架的输出工具，不构成投资建议。执行一致性优先于参数精确性。
