# 我的投资交易体系：产业研究增强型3M系统 V1.0

> 账户基础：100万元本金  
> 目标：五年内建立可持续、可审计、可迭代的职业投资能力。  
> 市场：A股为主。  
> 核心风格：事件驱动 + 五年产业逻辑 + 价值重估 + 资金趋势确认。  
> 核心约束：不使用借贷资金重仓；不与量化竞争速度；不因一次盈利扩大风险。

---

# 一、系统总纲

```text
产业逻辑定方向，
基本面定质量，
事件催化定时点，
价格与资金定强弱，
风险预算定仓位，
交易日志定进化。
```

系统名称中的3M：

- **Mind**：控制冲动、FOMO、回本欲望和持仓偏见；
- **Method**：产业研究 + 基本面 + 三重滤网 + 事件确认；
- **Money**：风险单位、仓位上限、组合风险和回撤控制。

我增加第四个模块：

- **Measurement**：交易日志、资金曲线、策略统计和版本审计。

# 二、第一目标与第二目标

## 第一目标：不被市场淘汰

- 不因单笔错误损失超过1%；
- 不因单月连续错误损失超过6%；
- 不因融资、期权卖方或重仓事件导致不可恢复损失；
- 保留至少24个月生活资金，不进入证券账户。

## 第二目标：建立稳定正期望

- 每种策略至少积累30—100笔可比样本；
- 规则执行率达到90%以上；
- 12个月滚动最大回撤控制在12%以内；
- 收益来源可解释，而不是依赖一两只暴涨股。

# 三、账户分层

| 账户/策略 | 目标比例 | 单股上限 | 主要周期 | 风险方式 |
|---|---:|---:|---|---|
| 核心复利账户 | 50%—60% | 15% | 1—3年 | 基本面、估值、逻辑止损 |
| 产业趋势账户 | 25%—35% | 10%—12% | 数周—数月 | 趋势止损、移动保护 |
| 事件交易账户 | 10%—15% | 5%—8% | 1天—数周 | 价格止损、时间止损 |
| 现金 | 动态 | — | — | 市场差时提高至50%以上 |

账户之间禁止临时挪用逻辑：

- 事件交易亏损后不能转核心仓；
- 核心仓不能因一天涨停全部变短线；
- 现金不是闲置，是选择权和风险缓冲。

# 四、能力圈与股票池

## 1. 重点方向

- 创新药与医药产业升级；
- AI算力、半导体和自主可控；
- 商业航天等国家战略产业；
- 石油、煤炭、黄金等事件与周期资源；
- 能够理解技术路线、商业模式和竞争壁垒的公司。

## 2. 排除条件

出现任一项原则上不交易：

- 财务造假或治理重大疑点；
- 流动性不足；
- 纯小作文，无可核实信息；
- 连续一字板，无法建立止损；
- 需要借贷或融资才能达到期望仓位；
- 重大临床/审批结果前却无法承受跳空；
- 交易逻辑无法用三句话说清。

# 五、四层研究框架

## 第一层：宏观与市场环境

观察：

- 流动性、利率、汇率和风险偏好；
- 主要指数趋势；
- 全市场成交额；
- 上涨/下跌家数；
- 大盘与小盘、价值与成长风格；
- 外部事件对A股的传导路径。

市场环境分级：

| 等级 | 状态 | 总仓位建议 |
|---|---|---:|
| A | 指数、成交、主线共振 | 70%—90% |
| B | 结构性行情 | 40%—70% |
| C | 震荡轮动 | 20%—50% |
| D | 系统性下跌 | 0%—30% |

## 第二层：产业与板块

评分30分：

- 国家战略/政策确定性：0—6；
- 产业景气和市场空间：0—6；
- 边际变化与预期差：0—6；
- 板块资金持续性：0—6；
- 估值与拥挤度：0—6。

低于18分不主动重仓。

## 第三层：公司基本面

评分25分：

- 产品/技术壁垒：0—5；
- 商业模式与盈利路径：0—5；
- 管理层与资本配置：0—5；
- 财务质量与现金流：0—5；
- 估值情景与安全边际：0—5。

创新药额外检查：

- 临床价值；
- 竞争格局；
- 适应症空间；
- 商业化能力；
- 现金储备；
- BD条款的确定部分与或有部分。

## 第四层：交易结构

评分15分：

- 周线趋势：0—3；
- 日线结构：0—3；
- 成交量与承接：0—3；
- 板块联动：0—3；
- 风险收益比：0—3。

交易结构低于9分，只能观察。

# 六、三重滤网执行系统

## 第一滤网：周线/市场方向

允许主动做多的条件至少满足三项：

- 指数位于20周均线之上或周线趋势改善；
- 目标板块相对强度进入前20%；
- 周线MACD柱改善；
- 板块成交额持续放大；
- 核心催化不是一次性小作文。

## 第二滤网：日线机会

优先选择三类结构：

1. **上升趋势回调**：回到10/20日均线附近，缩量，未破前低；
2. **平台突破**：放量突破，次日不高开低走；
3. **事件后的二次确认**：第一波情绪释放后形成平台，再突破。

禁止：

- 连续加速后远离均线追入；
- 板块退潮中的个股独涨；
- 重大利好高开低走后盲目抄底。

## 第三滤网：执行

盘中只看：

- 触发价是否达到；
- 板块是否同步；
- 均价线和开盘区间是否有承接；
- 是否出现超出计划的跳空；
- 实际风险收益比是否仍合格。

未经盘前计划的股票，盘中不得直接重仓买入。

# 七、三类核心策略

## 策略A：创新药价值重估

典型案例：迪哲医药。

### 入池条件

- 核心产品具备临床差异化；
- 商业化收入加速；
- 医保、FDA、NMPA或全球BD形成硬催化；
- 现金流和融资风险改善；
- 估值尚未完全依赖最乐观情景。

### 买入方式

- 基本面初步确认：观察仓2%—3%；
- 日线趋势确认：增加至5%—8%；
- 催化兑现且价格结构健康：最高10%—15%；
- 二元结果公布前不满仓押注。

### 卖出条件

- 临床价值被证伪；
- 商业化显著低于预期；
- 竞争产品改变格局；
- 现金消耗与融资风险恶化；
- 估值已透支乐观情景；
- 事件交易部分跌破趋势保护位。

## 策略B：事件驱动第二波

典型方向：地缘冲突—油价—油服板块—通源石油。

### 原则

- 不抢无法验证的第一秒；
- 先确认商品价格、板块联动和龙头反馈；
- 寻找低位放量、横盘承接或第一次分歧后的二次机会；
- 持有期短，使用价格与时间止损；
- 事件降温、商品转弱或板块资金流出时退出。

## 策略C：核心复利

适用：商业模式清晰、长期ROIC改善、产业空间大、估值合理的公司。

- 分批买入；
- 不用3%日线波动触发长期止损；
- 以季度/年度基本面、估值和竞争优势管理；
- 当单股因上涨超过账户15%时进行风险再平衡。

# 八、风险与仓位系统

## 1. 单笔风险

| 交易等级 | 账户风险比例 |
|---|---:|
| 观察/试错 | 0.25%—0.30% |
| 普通信号 | 0.50% |
| 高质量共振 | 0.70% |
| 绝对上限 | 1.00% |

100万元账户对应：2500元、5000元、7000元、10000元。

## 2. 仓位公式

```text
风险预算R = 账户权益 × 风险比例
每股风险 = 入场价 - 初始止损价 + 跳空/滑点缓冲
股数 = floor(风险预算R ÷ 每股风险 ÷ 100) × 100
```

示例：

- 账户100万元；
- 风险比例0.5%，R=5000元；
- 入场50元；
- 止损46.5元；
- 跳空缓冲0.5元；
- 每股风险4元；
- 可买1250股，按整手取1200股；
- 名义仓位6万元。

## 3. 组合限制

- 全部开放风险合计≤3%；
- 单一行业总仓位≤25%；
- 单一事件因子总仓位≤15%；
- 高波动创新药总仓位≤20%；
- 单只事件股≤8%；
- 单只核心股≤15%。

## 4. 回撤控制

| 回撤状态 | 动作 |
|---|---|
| 当月-2% | 新开仓风险减半 |
| 当月-4% | 停止事件交易 |
| 当月-6% | 停止主动开仓，完成审计 |
| 高点回撤-8% | 总仓位降至30%以下 |
| 高点回撤-12% | 暂停常规实盘，模拟/极小仓恢复 |

# 九、卖出系统

## 1. 初始止损

- 放在交易逻辑失效处，而不是随意固定百分比；
- 加入T+1和隔夜跳空缓冲；
- 如果止损太远导致仓位过小，接受小仓或放弃。

## 2. 分批止盈

- 达到+2R，可兑现1/3并把保护位上移；
- 达到估值目标区，分批减仓；
- 重大利好后连续加速，不再加仓；
- 高开低走、放量滞涨、板块退潮时降低交易仓。

## 3. 移动止损

根据策略选择一种，不临时切换：

- 前一波段低点；
- 10日/20日均线；
- ATR或波动率止损；
- 事件后平台下沿；
- 时间止损。

## 4. 逻辑止损

核心投资在以下情况退出：

- 产品价值被证伪；
- 竞争优势消失；
- 管理层资本配置恶化；
- 盈利路径改变；
- 估值严重透支且未来回报不足。

# 十、心理操作规程

## 1. 禁止交易状态

出现任一项，当天不主动开新仓：

- 睡眠不足；
- 与工作/家庭冲突后情绪激动；
- 上一笔大亏，强烈想回本；
- 上一笔大赚，想扩大仓位；
- 害怕错过评分≥4/5；
- 没有完成盘前计划。

## 2. 30分钟冷却规则

任何临时发现的热点，先写下：

- 信息来源；
- 催化事实；
- 失效条件；
- 止损；
- 仓位。

等待至少30分钟，仍满足规则才允许小仓。

## 3. 连续亏损规则

- 连续2笔-1R：下一笔风险减半；
- 连续3笔亏损：暂停两天，复盘市场状态与执行；
- 连续5笔亏损：暂停该策略，至少复核30笔历史样本。

# 十一、每日工作流

## 盘前

1. 查看指数、外围市场、商品、汇率与重要公告；
2. 判断市场A/B/C/D状态；
3. 更新板块强度；
4. 只保留3—5只重点候选；
5. 写入场、止损、目标、股数和不交易条件；
6. 检查已有仓位的保护位。

## 盘中

1. 只执行计划内交易；
2. 观察板块与个股是否共振；
3. 不因拉升临时提高买入价；
4. 不因亏损临时扩大止损；
5. 新热点先进入观察，不直接重仓。

## 盘后

1. 保存日线、分时和板块截图；
2. 记录计划与实际差异；
3. 计算盈亏R；
4. 标记是否违规；
5. 更新产业与公告数据库；
6. 给明日持仓制定明确方案。


# 十四、90天落地计划

## 第1—30天：建立基础设施

- 建立股票池、交易计划和日志模板；
- 所有新交易风险≤0.3%；
- 完成至少10笔完整记录；
- 不考核收益，只考核执行率。

## 第31—60天：验证策略

- 区分创新药重估、事件第二波、趋势回调三类；
- 统计每类胜率、R和违规；
- 删除无法清晰定义的交易；
- 风险上限仍不超过0.5%。

## 第61—90天：形成V1.1

- 至少完成30笔同口径样本；
- 对规则做一次集中修改，不逐笔修改；
- 只有期望值为正且执行率≥90%的策略，才可提升至0.7%风险；
- 形成月度投资委员会式自我报告。

# 十六、我的最终纪律

1. 不借贷炒股。
2. 不因一次20%盈利把运气当能力。
3. 不在连续涨停后用重仓表达信仰。
4. 不用“国家支持、行业空间大”替代公司分析。
5. 不在临床、政策、战争等二元事件前满仓赌博。
6. 不在板块退潮时用长期逻辑对抗流动性。
7. 不移动止损来避免认错。
8. 不频繁更换系统，只依据统计样本迭代。
9. 每笔交易保留原始计划与截图。
10. 首要目标不是最快赚钱，而是形成可持续复利能力。
