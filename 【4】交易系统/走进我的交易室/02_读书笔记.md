# 《走进我的交易室》读书笔记

> 写作视角：第一人称，面向A股实战。  
> 核心问题：如何把100万元本金保护好，并在五年内建立可复制的职业投资能力。

---

## 一、我为什么要读这本书

我过去更关注“买什么会涨”，但职业交易真正需要回答六个问题：

1. 为什么是这只股票；
2. 为什么是现在；
3. 在什么价格进入；
4. 判断错误在哪里退出；
5. 判断正确如何持有；
6. 买多少才不会因一次错误伤筋动骨。

《走进我的交易室》最重要的改变，是把注意力从“寻找牛股”转向“管理自己、管理交易、管理账户”。它不是承诺预测市场，而是教我在不确定市场中建立稳定行为。

---

# 第一部分：金融丛林中的入门训练

## 二、投资、交易还是赌博

### 1. 三者的区别

投资者主要研究企业长期价值、现金流和资本回报；交易者主要研究价格、趋势、动能和市场参与者行为；赌徒主要追求刺激，并把希望当作计划。

同一只股票可以被三种方式持有：

- 我研究迪哲医药的产品、商业化和全球授权，以三年为周期，是投资；
- 我根据公告催化、板块强度和日线结构持有数周，是交易；
- 我因为看到20%涨停，害怕错过而满仓追入，是赌博。

真正危险的不是交易，而是**用投资的借口拖延交易止损，或者用交易的冲动破坏长期投资仓位**。

### 2. 我的改进

每次下单前必须标记账户类型：

```text
A. 核心投资
B. 产业趋势交易
C. 事件驱动交易
D. 观察仓
```

不同类型使用不同持有周期、止损方式和仓位上限，禁止交易中途偷换定义。

---

## 三、选择什么市场和品种

书中讨论股票、期货、期权等市场。对我而言，重点不是哪个市场收益最高，而是哪个市场最适合现阶段能力。

我的主战场应是A股股票与ETF，因为：

- 我熟悉中国政策、产业和公司信息；
- 100万元本金足以进行分层配置；
- 股票不存在期货的强制杠杆和到期问题；
- 我尚未形成稳定期望值前，不适合通过期权或融资放大波动。

品种筛选标准：

1. 流动性充足，不能因卖不出去而失去止损能力；
2. 业务和催化能够理解；
3. 信息披露相对透明；
4. 波动与仓位可匹配；
5. 不参与纯小作文、连续一字板和无法设置合理止损的交易。

---

## 四、交易前的准备

新手常把软件、指标和消息源当作优势。书中更强调准备工作的完整性：

- 数据是否可靠；
- 交易成本是否计入；
- 方法是否经过验证；
- 行动计划是否写清；
- 是否能够独立承担结果。

我的软件工程背景容易让我陷入“工具越复杂越专业”的错觉。事实上，交易系统首先要可执行。一个由周线趋势、日线回调、止损和仓位构成的简单系统，可能优于十几个指标互相矛盾的复杂系统。

# 第二部分：成功交易的三个要素——3M

## 五、Mind：自律的交易者

### 1. 最大的对手不是市场，而是自我破坏

常见自我破坏行为包括：

- 亏损后急于回本；
- 盈利后自信膨胀；
- 把一次成功当成稳定能力；
- 因为持有而只接受利好信息；
- 临时移动止损；
- 明知没有信号仍因无聊交易；
- 把满仓看作“信念强”，把止损看作“认输”。

我在事件交易中最需要警惕的是：推演正确并获利后，容易扩大下一笔仓位。市场不会因为上一笔正确而降低下一笔风险。

### 2. 专业交易者的心理结构

专业并不是没有恐惧和贪婪，而是：

```text
有情绪，但不让情绪获得下单权限。
```

我需要把情绪变成可记录字段：

- 进场前兴奋度0—5；
- 害怕错过程度0—5；
- 对亏损的抵触程度0—5；
- 是否想证明自己；
- 是否因为上一笔结果改变仓位。

当“兴奋度+害怕错过”大于6时，只允许观察或使用半仓风险单位。

### 3. 谦逊的含义

谦逊不是没有观点，而是承认：

- 我的判断可能错误；
- 好公司也会下跌；
- 好消息可能已被价格反映；
- 市场可以比我预期更极端；
- 我只能控制买点、卖点、仓位和行为，不能控制结果。

## 六、Method：技术分析与交易方法

### 1. 技术分析的正确位置

技术分析不是预测未来的水晶球，而是对当前趋势、动能、波动和供需状态的结构化描述。

对我而言，基本面和产业研究解决“值不值得跟踪”，技术与资金结构解决“是否值得现在承担风险”。

```text
基本面决定候选池；
价格行为决定时点；
风险管理决定仓位。
```

### 2. 趋势指标与摆动指标不能混用

趋势指标在有趋势市场中有效，摆动指标在震荡市场中有效。如果不先识别市场状态，就会：

- 在强趋势中因“超买”过早卖出；
- 在持续下跌中因“超卖”不断抄底；
- 在横盘中追逐假突破。

因此第一步不是找信号，而是判断市场处于：上升趋势、下降趋势、区间震荡还是事件冲击。

### 3. 三重滤网系统

三重滤网的思想是让不同周期承担不同职责。

#### 第一层：长周期决定方向

我使用周线或相当于日线5倍左右的周期，观察：

- 指数与板块是否在中期上升；
- 周线EMA斜率；
- 周线MACD柱方向；
- 产业主线是否获得持续资金。

只在长周期向上时主动做多。长周期向下时，降低仓位或等待。

#### 第二层：中周期寻找机会

在日线中寻找：

- 上升趋势中的回调；
- 突破后的缩量确认；
- 催化出现后的承接；
- 价格回到价值区而趋势未破坏。

#### 第三层：短周期执行

使用30分钟、60分钟或日内关键结构：

- 突破触发；
- 均价线承接；
- 前高/前低；
- 成交量变化；
- 避免开盘情绪最极端时追价。

A股是T+1，第三层不能只考虑“进得去”，还必须考虑次日跳空与无法当日纠错。

### 4. 冲动系统

冲动系统把趋势与动能结合。经典结构以短期指数移动平均线方向和MACD柱方向判断：

- 两者同时向上：多头冲动，不做空；
- 两者同时向下：空头冲动，不做多；
- 两者不一致：等待或管理已有仓位。

我不需要机械复制参数，而应保留思想：**只有趋势和动能相互支持时，才允许主动进攻。**

A股应用：

```text
周线趋势向上 + 日线收盘站上20日线 + MACD柱改善 + 板块强度前20%
= 允许寻找买点
```

### 5. 进场前先设计出场

这是全书对我最实用的原则之一。下单前必须写出：

1. 入场价；
2. 初始止损价；
3. 第一利润目标；
4. 趋势延续时的移动止损方法；
5. 时间止损；
6. 逻辑失效条件。

没有止损就无法计算风险，没有风险就无法计算仓位。

### 6. 出场比进场更重要

新手不断寻找完美买点，专业者花更多时间设计退出。退出包括：

- 防守型止损：证明判断错误；
- 利润目标：价格到达预期区间；
- 移动止损：保护趋势利润；
- 时间止损：催化未兑现或价格迟迟不动；
- 逻辑止损：基本面、政策、临床或竞争格局改变。

## 七、Money：资金管理公式

### 1. 2%规则的本质

书中的2%规则要求单笔交易最大计划亏损不超过账户权益的一定比例。重点不是“2”这个数字，而是：

```text
先确定最多亏多少钱，再根据止损距离计算可以买多少。
```

仓位公式：

```text
单笔风险预算 = 账户权益 × 风险比例
每股风险 = 入场价 - 止损价 + 滑点/跳空缓冲
可买股数 = 单笔风险预算 ÷ 每股风险
```

A股高波动、T+1和20%涨跌停使实际损失可能超过计划止损。因此我的常规风险比例应低于原书上限：

- 普通交易：0.5%；
- 高质量交易：0.7%；
- 绝对上限：1.0%；
- 科创板、临床事件、连续涨停后交易：0.3%—0.5%。

### 2. 6%规则的本质

6%规则不是鼓励亏到6%，而是在连续错误时强制停止增加风险。

我的本地化版本：

- 月度回撤达到2%：新开仓风险减半；
- 达到4%：停止事件交易，只管理已有仓位；
- 达到6%：本月停止主动开仓，完成交易审计；
- 从历史高点回撤达到8%：账户总仓位降至30%以下；
- 达到12%：暂停实盘，使用模拟与小仓恢复。

### 3. 相关性风险

同时持有迪哲医药、益方生物、贝达药业和昭衍新药，不等于四笔独立交易。在创新药板块退潮时，它们可能同步下跌。

因此资金管理不仅看单股，还要看：

- 同一行业总仓位；
- 同一事件因子总仓位；
- 同一市场风格总仓位；
- 所有持仓止损触发后的合计损失。

### 4. R倍数

把单笔初始风险定义为1R：

- 亏损达到止损：-1R；
- 盈利等于初始风险：+1R；
- 盈利是初始风险3倍：+3R。

R倍数让我能比较不同价格、不同仓位的交易，并判断系统期望值：

```text
期望值 = 胜率 × 平均盈利R - 亏损率 × 平均亏损R
```

胜率不是唯一目标。40%胜率、平均盈利2.5R、平均亏损1R的系统仍可能优秀。

# 第三部分：走进交易室

## 八、有条理的交易者

### 1. 交易电子表格

每笔交易至少记录：

- 日期、代码、账户类型；
- 交易逻辑与催化；
- 长中短周期状态；
- 入场、止损、目标；
- 风险预算、股数、总仓位；
- 实际成交与滑点；
- 情绪评分；
- 出场原因；
- 盈亏金额与R倍数；
- 是否遵守规则。

### 2. 资金曲线

资金曲线比单只牛股更能反映能力。需要同时观察：

- 账户净值；
- 最大回撤；
- 20日和60日资金曲线均线；
- 交易系统分策略收益；
- 违规交易造成的损失。

如果资金曲线向下，正确做法不是加大仓位回本，而是减少风险、寻找系统或执行问题。

### 3. 交易日记

交易日志不仅记录结果，还要保存进场前截图和当时想法。否则复盘会被事后偏见污染。

我要区分四种结果：

| 过程 | 结果 | 评价 |
|---|---|---|
| 正确 | 盈利 | 保持规则 |
| 正确 | 亏损 | 接受概率结果 |
| 错误 | 盈利 | 最危险，不能奖励违规 |
| 错误 | 亏损 | 立即修复行为 |

### 4. 行动计划

行动计划必须在市场开盘前完成，盘中只负责执行。计划至少包括：

- 今日市场状态；
- 重点板块；
- 候选股；
- 触发价；
- 止损价；
- 仓位；
- 不交易条件；
- 已有仓位的处理方案。

## 九、从新手到职业交易者

### 1. 新手阶段

特征：寻找秘诀、频繁交易、关注收益金额、没有稳定记录。

目标：学会不重伤账户，完成100笔小风险、完整记录的交易样本。

### 2. 半专业阶段

特征：已有方法，但执行不稳定；能盈利，也会因违规回吐。

目标：提高规则执行率，明确哪些策略有正期望，删除无效交易。

### 3. 职业阶段

特征：把交易视为经营活动；重视资本保护、流程、统计和时间分配。

职业的标准不是某个月赚20%，而是：

- 多种市场环境下仍能控制回撤；
- 收益来源可解释；
- 规则可重复；
- 亏损不会破坏生活和心理；
- 能持续更新方法而不追逐噪声。

## 十、对A股市场的本地化修正

### 1. T+1修正

当天买入后无法卖出，因此：

- 开盘追高风险更大；
- 必须增加隔夜跳空缓冲；
- 重大公告、临床数据和政策窗口前降低仓位；
- 不用理论止损假装能完全控制实际损失。

### 2. 涨跌停修正

科创板和创业板单日波动可达20%。连续涨停后，止损距离会急剧扩大，按风险公式计算出的合理仓位应显著下降。如果仍想重仓，说明买入依据是贪婪而非风险管理。

### 3. 题材轮动修正

量化资金和短线资金加快板块轮动。个人投资者不应竞争毫秒速度，而应：

- 研究产业逻辑和公告含金量；
- 等待第一波情绪释放后的承接；
- 做第二波或趋势确认；
- 降低交易频率；
- 用更长周期过滤噪声。

### 4. 基本面与技术面分工

```text
产业逻辑：决定是否值得长期跟踪
公司基本面：决定候选股质量
公告催化：决定预期是否发生变化
技术结构：决定何时承担风险
资金管理：决定承担多少风险
交易日志：决定能否持续进化
```

## 十一、我读完后的十个改变

1. 不再把“看对方向”当作完整交易。
2. 每笔先写退出，再写买入。
3. 用风险金额而不是投入金额定义仓位。
4. 把好公司与好价格分开。
5. 把事件交易与长期投资分账户管理。
6. 连续亏损时减少交易，不加码回本。
7. 把错过视为零损失，而非必须补票。
8. 用资金曲线评价自己，不用单只股票炫耀能力。
9. 用100笔样本评估规则，不用3笔结果改系统。
10. 交易的第一目标是未来仍有资格参与市场。

---

## 十二、全书最终结论

《走进我的交易室》不是一本教我“下一只股票买什么”的书，而是一本教我如何经营交易事业的书。

我的最终理解是：

```text
预测提供机会，纪律把机会变成交易，资金管理让交易能够重复，记录让重复逐渐进化。
```
