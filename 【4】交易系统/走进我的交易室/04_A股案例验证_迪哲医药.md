# A股案例验证：迪哲医药（688192）

> 用户原文中的“迪泽医药”应为**迪哲医药**。  
> 目的：不是给出当前买卖建议，而是用真实行情检验《走进我的交易室》的心理、方法和资金管理框架。  
> 数据截点：2026-07-23收盘。

---

## 一、公司与事件事实

迪哲医药是一家创新生物医药公司，核心领域为肿瘤和血液系统疾病。公开信息显示：

1. 2025年营业收入约8.01亿元，同比增长122.60%；
2. 舒沃哲和高瑞哲进入国家医保目录后，商业化收入快速增长；
3. 舒沃哲于2025年7月获得美国FDA加速批准；
4. 2026年7月，公司与阿斯利康签署舒沃哲全球独家开发、商业化许可协议；
5. 协议包括6亿美元不可返还首付款、最高4亿美元临床开发里程碑、最高5亿美元销售里程碑，以及销售特许权使用费；
6. 公司公告同时明确：交易生效需满足交割与监管条件，后续里程碑和销售存在不确定性。

这意味着基本面发生了显著的价值重估催化，但仍然不能推出“任何价格买入都正确”。

# 三、用Mind检验：心理是否合格

## 场景A：7月14日看到20%涨停后害怕错过

典型心理：

- “这么大的BD一定还有几个板”；
- “首付款6亿美元，市值肯定低估”；
- “今天不买明天买不到”；
- “创新药主线来了，应该满仓”。

艾尔德式审查：

1. 是否因消息刺激而兴奋？是。
2. 是否能够给出合理止损？很难。
3. 当日买入能否当日纠错？不能，A股T+1。
4. 次日可能高开或低开多少？不确定，且20%波动制度放大风险。
5. 是否把优秀基本面等同于短期价格必涨？是。

结论：即使事件质量很高，**心理状态与交易结构都不支持大仓追入**。

## 场景B：原有持仓者连续涨停后不愿卖

典型心理：

- 盈利使人感觉自己理解了全部未来；
- 把浮盈当作“市场送的钱”，容忍巨大回撤；
- 因为长期看好，拒绝对事件交易部分止盈。

正确做法是区分核心仓和交易仓：

- 核心仓根据长期估值与基本面持有；
- 事件仓在价格冲动转弱、量价异常或跌破保护位时退出；
- 不让“长期逻辑”成为短线利润回吐的借口。

# 四、用Method检验：方法是否给出可执行信号

## 1. 第一层滤网：周线与产业方向

当时创新药板块具备政策、商业化和BD交易催化，迪哲医药的公司基本面也出现商业化与全球化进展。第一层滤网可以把它列入高优先级候选池。

但第一层只回答“方向值得关注”，不能直接回答“7月15日67.60元值得追”。

## 2. 第二层滤网：日线结构

在许可协议公告前，股价已从6月22日最低35.73元上行至7月13日收盘46.94元，区间涨幅较大，趋势已明显升温。

7月14日、15日连续20%涨停后：

- 价格远离均线和常规价值区；
- 止损距离显著扩大；
- 风险收益比难以估算；
- 市场情绪高度一致，反而缺少低风险入场位置。

因此日线方法应给出：

```text
持仓者管理利润；空仓者不在第二个涨停附近建立常规仓位。
```

## 3. 第三层滤网：执行结构

7月16日：

- 开盘66.00元；
- 盘中最高69.58元；
- 收盘64.00元，下跌5.33%；
- 振幅扩大，冲动开始降温。

这不是必然反转信号，但说明：

- 继续追高的赔率下降；
- 事件交易仓应开始用前低、日内结构或移动止损保护；
- 空仓者应等待缩量稳定、均线跟上或形成新平台，而不是立即接力。

# 五、用Money检验：仓位是否合理

## 1. 100万元账户的风险预算

设常规单笔风险为0.7%：

```text
单笔允许计划亏损 = 1,000,000 × 0.7% = 7,000元
```

### 假设一：7月14日涨停价56.33元追入

若技术止损只能放在公告日最低价45.45元附近，并加入约1.50元跳空/滑点缓冲：

```text
每股风险 = 56.33 - 45.45 + 1.50 = 12.38元
可买股数 = 7,000 ÷ 12.38 ≈ 565股
A股按100股取整，只能买500股
名义仓位 ≈ 28,165元，占账户2.8%
```

这说明：按照风险管理，越是波动巨大的“确定性机会”，合理仓位反而越小。

若有人在此处投入30万元，相当于约5325股；同样的每股风险下，计划风险约6.59万元，即账户6.6%，一笔交易就触及月度停止线。

### 假设二：7月16日66元附近追入

若止损放在62元附近，考虑2元隔夜缓冲：

```text
每股风险 = 66 - 62 + 2 = 6元
可买股数 = 7,000 ÷ 6 ≈ 1,166股
按整手取1,100股
名义仓位约72,600元，占账户7.3%
```

这仍然不是“大机会就重仓”，而是由止损距离严格限制仓位。

## 2. 创新药二元风险修正

创新药还存在临床、审批、竞争与商业化不确定性。对于重大临床结果公布前的仓位，我的风险比例应降至0.3%—0.5%，并把理论止损之外的跳空损失纳入压力测试。

# 六、三种合理交易计划

## 计划A：公告前已有低位持仓

适用：基于基本面和趋势，在40—48元区间已建立仓位。

执行：

1. 7月14日涨停不加仓；
2. 7月15日第二个涨停，将事件交易仓止损上移；
3. 可分批兑现1/3—1/2，回收本金或锁定2R以上利润；
4. 7月16日冲高回落、收盘转弱时继续降低交易仓；
5. 核心仓单独按长期估值和基本面管理。

优点：既保留长期价值重估的参与权，也避免全部浮盈暴露于短期回撤。

## 计划B：公告后空仓者

执行：

1. 不追7月14日和15日涨停；
2. 等待3—10个交易日形成平台；
3. 观察板块是否继续强、成交量是否收敛、价格是否守住关键均线；
4. 只有出现可定义止损的二次突破或回踩确认才进场；
5. 若没有低风险结构，接受错过。

## 计划C：长期投资者

执行：

1. 重估首付款、里程碑、特许权和现金流影响；
2. 分开计算已确定价值与概率加权价值；
3. 检查许可协议交割、监管、产品适应症和竞争风险；
4. 采用分批建仓，单股长期上限原则上不超过账户15%；
5. 在估值透支乐观情景时减仓，而不是只因公司优秀永久持有。

# 七、这笔案例验证了哪些原则

1. **好公司不等于好买点。**
2. **公告质量与交易赔率是两个问题。**
3. **没有可执行止损，就没有合理仓位。**
4. **连续涨停会放大心理冲动和止损失效风险。**
5. **预先持仓者与公告后追入者面对的是完全不同的赔率。**
6. **核心仓与事件仓必须分开管理。**
7. **正确做法可能是放弃，而不是强行参与。**
8. **盈利保护依赖移动止损和分批退出。**
9. **所有判断都要回到R倍数，而不是“能涨多少”的想象。**
10. **交易日志必须保存公告出现当日的原始计划，防止事后美化。**

# 八、案例复盘结论

如果我在公告前基于产业、基本面和趋势持有，许可协议是价值重估催化；如果我在两个20%涨停后才因害怕错过而进入，同一事件可能变成低赔率交易。

```text
同一家公司、同一条利好、不同的买入价格和仓位，
可以分别构成优秀投资、合格交易或危险赌博。
```

这正是《走进我的交易室》的核心：市场机会并不自动转化为账户利润，必须经过心理、方法和资金管理三道门。
