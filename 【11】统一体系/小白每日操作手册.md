# 小白每日操作手册（零基础版）

> **定位**：每天照着做的固定流程，不需要懂原理。进阶逻辑见 [[超短操作手册]]、[[基金经理日常工作流]]。
> **一句话**：晚上 `run_all` 定计划 → `from-scan --execute` 建仓 → 盘中只按纸上的价格执行 → 卖前 `sell-check`、卖后 `update` → 周末看周报里的纪律审计。

---

## 第 0 步：准备工作（每个交易日只做一次）

1. 打开文件夹 `E:\Billion\Invest`，在地址栏输入 `powershell` 回车（或右键 →「在终端中打开」）。
2. 后面所有命令都在这个黑窗口里输入，每条命令输完按回车。

> 如果看到红字报 `No module named xxx`，跑一次：`pip install -r requirements.txt`
>
> 可选：想让系统自动判定候选⑧催化，配置一次 LLM Key：`$env:KIMI_API_KEY="sk-..."`（PowerShell 只对当前窗口生效；永久生效需设系统环境变量）。不配置也能用——报告会列出公告标题供人工核对。

---

## 第 1 步：盘前（开盘前 30-40 分钟，最晚 9:15 前开始）

```powershell
python run_all.py
```

它会自动跑 5-15 分钟（抓数据→扫描→监控→日报）。**如果今天已经跑过一次**，想省时间用 `python run_all.py --skip-fetch`。

跑完后，用 Obsidian 或记事本打开当天扫描报告：

```
E:\Billion\Invest\output\market_scans\market_scan_当天日期.md
```

**只看三个地方：**

**① 第一节「市场状态」——决定今天做不做**

| 状态 | 你的动作 |
|---|---|
| A 或 B | 正常执行下面的步骤 |
| C（震荡轮动） | 可以做，但仓位减半 |
| D | **今天不开新仓**，只管已有持仓 |

**② 第五节「超短热点池」——今天的候选名单**

看「热点池突破候选」表：有名称、来源、板块和**推荐分析**（系统按买入规则 8 条自动核对，满足 4 条以上才允许买入；⑧事件催化最重要——配置 LLM Key 后系统自动读公告判定，未配置时报告给出公告标题自己核对）。从推荐分析条数多的里面挑 **1-3 只**你看得懂的。

**③ 顶部「持仓监控」——手里股票的警报**

如果有「触发止损」「跌破退出通道」字样，今天优先处理持仓，别想着买新的。

**然后拿纸笔为每只候选写下三行字**（血的教训：操作前先写下买点和卖点）：

```text
股票：xxxxxx（名称）
触发价：__.__（表里的通道高点附近，到了才买，不到不买）
止损价：__.__（跌到说明判断错了，无条件卖）
失效条件：________（例：板块跌出涨幅前 5、龙头跌停）
```

## 第 2 步：一键建仓（前一晚或开盘前做好）

对挑中的每只股票，先**预览**（不会写入）：

```powershell
python review/cli.py from-scan 601606
```

系统打印收盘价、通道高点、建议止损。确认后**正式建仓**：

```powershell
python review/cli.py from-scan 601606 --execute
```

这一步自动完成四件事：按 3.25 万本金算股数（最多亏 1%≈325 元反推）→ 过合规闸门 → 写入交易日志 → 在 `【10】实盘记录\交易日志\` 生成**买入卡**。

**两种「被拒绝」都是系统在保护你：**

- 「禁买板块」→ 创业板（300/301 开头），纪律就是不买，**放弃**。
- 其他「高级违规」→ 仓位/风险超限，**放弃或缩小仓位**，不要加 `--force`。

**候选股不在扫描报告里时**（自己别处看到的）手动来：

```powershell
python position_calculator.py -s 600519 -e 触发价 --stop 止损价 -t 事件    # 先算能买多少股
python review/cli.py add 600519 --account 事件 --system HOT-S --entry 触发价 --stop 止损价 --risk 1.0 --shares 算出来的股数
```

## 第 3 步：盘中（9:30-15:00）——只执行，不思考

- 券商 App 按纸上写的**触发价**挂买单。价格没到 → 不买，错过就错过。
- 止损价到了 → 卖，不讨价还价。
- **不看 9:15-9:25 集合竞价分时**（已识别的洗盘手法），不看评论区。
- 想临时买计划外的股票 → 先等 30 分钟，写下理由和止损，仍想做才允许小仓（周报纪律审计会标出所有 <30 分钟换仓）。
- A 股 T+1：今天买的明天才能卖。

---

## 第 4 步：卖出那天（完整流程）

**① 卖之前先检查**（10 秒钟）：

```powershell
python review/cli.py sell-check 605388
```

它告诉你：止损/退出通道有没有触发、持有几天、还在不在热点池、**建议挂单价**（= 最近收盘 × 0.99，「挂低 1% 防未成交」教训的固化）。

**② 券商 App 按建议价卖出。**

**③ 卖完落库**（2 分钟，忘了周报就不准）。先查交易编号：

```powershell
python review/cli.py list
```

找到 `T20260xxx_xxxxxx` 编号，然后（换成实际数据）：

```powershell
python review/cli.py update T20260803_a1b2c3 --exit-price 6.15 --exit-date 2026-08-04 --exit-time 09:35:00 --exit-reason "触发止损"
```

> 买入用 `from-scan --execute` 做的会自动落库；实际成交价与计划价有出入可加 `--note "实际成交 6.02"` 备注。

## 第 5 步：周末（1 分钟）

```powershell
python review/cli.py weekly
```

（电脑常开且运行 `python server.py` 时会自动生成：周五 15:45 周报、月末 16:00 月报。）

去 `【10】实盘记录\每周复盘\` 打开最新周报，重点看两节：

- **纪律审计**：追高接回/闪电换仓/禁买板块出现几次 → 出现就是犯错，下周改；
- **关键指标**：胜率、总盈亏金额。R 系指标（期望值/PF）等带止损的新交易攒够 5 笔后才有意义——**每笔买入必须设止损价**。

---

## 常见情况

- **命令报红字**：先看最后一行英文错误；数据接口偶发失败就重跑一次；还不行把红字发给 AI 助手。
- **今天没有候选 / 推荐分析都不到 4 条**：空仓等待。没机会买入可加自选，千万不要急着乱买。
- **热点池显示「未构建/降级」**：数据源临时故障，用板块排名 + 人工涨停复盘代替，次日自动恢复。
- **第一周建议**：只用 1 只股票走完整流程（买→持有→卖→update→看周报），跑通一遍比看懂所有细节更重要。
