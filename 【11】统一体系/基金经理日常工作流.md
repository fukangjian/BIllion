# 基金经理日常工作流

> **定位**：AI 增强型职业投资者的固定日常节奏。  
> **原则**：人负责战略与决策，AI/量化负责信息整理与计算，纪律负责执行。  
> **关联文档**：[[投资体系_V5.0]] · [[买入卡模板]] · [[周报模板]] · [[90天实盘训练计划]]

---

## 工作流总览

```text
盘前 1 小时  →  盘中执行  →  盘后 1 小时  →  周末深度研究
   计划            纪律            复盘            进化
```

| 时段 | 时长 | 核心产出 |
|---|---:|---|
| 盘前 | 60 分钟 | 市场状态判断 + 3—5 只候选 + 交易计划 |
| 盘中 | 交易时段 | 只执行计划，记录异常 |
| 盘后 | 60 分钟 | 日志 + R 计算 + 持仓方案 |
| 周末 | 2—3 小时 | 周报 + 深度研究 + 股票池更新 |

---

## 一、盘前 1 小时流程

> 时间：08:30—09:30（A 股集合竞价前）

### Step 1 · 宏观与市场扫描（15 分钟）

查看以下信息，形成当日市场快照：

| 类别 | 关注项 | 信息源 |
|---|---|---|
| **指数** | 上证、沪深 300、创业板、科创 50 趋势 | 东方财富 / 同花顺 |
| **外围** | 美股、港股、日经、VIX | Wind / 财经 APP |
| **商品** | 原油、黄金、铜、天然气 | 文华财经 |
| **汇率** | 美元/人民币、美元/日元 | 央行 / 外汇交易中心 |
| **公告** | 持仓公司公告、重大政策 | 巨潮资讯 / 国务院 |

记录至日复盘文件的市场快照区。

### Step 2 · 判断市场 A/B/C/D 状态（10 分钟）

依据 [[投资体系_V5.0]] 第 1 层分级：

| 等级 | 状态 | 总仓位建议 | 判断依据 |
|---|---|---:|---|
| **A** | 指数、成交、主线共振 | 70%—90% | 指数趋势向上 + 成交额放大 + 主线清晰 |
| **B** | 结构性行情 | 40%—70% | 指数震荡但主线板块强势 |
| **C** | 震荡轮动 | 20%—50% | 无明确主线，热点快速轮动 |
| **D** | 系统性下跌 | 0%—30% | 指数趋势向下 + 广度恶化 |

**今日市场状态**：___  
**较昨日变化**：升 / 降 / 不变  
**今日建议总仓位**：___ %

### Step 3 · 更新板块强度（10 分钟）

- 查看板块相对强度排名（量化工具 / 手动记录 Top 10）
- 标注能力圈内板块：启动 / 发酵 / 加速 / 高潮 / 分歧 / 退潮
- 检查持仓所在板块状态是否变化

### Step 4 · 审阅 AI 日报（10 分钟）

运行 `Invest/run_all.py`（或分步运行 `pipeline/run_daily.py` + `research/run_daily_report.py`），审阅 `Invest/output/` 下的报告：

- [ ] 持仓公司最新公告摘要（`output/announcements/`）
- [ ] 能力圈产业关键数据变化
- [ ] 20/55 日突破候选清单（`output/market_scans/`）
- [ ] 每日研究日报（`output/daily_reports/`）
- [ ] 风险预警（回撤、风险簇、集中度）

> AI 负责整理，人负责判断和行动。AI 不替代决策责任。

### Step 5 · 筛选重点候选（10 分钟）

从股票池 A 级中**只保留 3—5 只**重点候选：

| # | 股票 | 策略 | 触发价 | 止损 | 风险 R | 优先级 |
|---|---|---|---:|---:|---:|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

其余标的移回观察，不在盘中临时决策。

### Step 6 · 编写交易计划（10 分钟）

对每只候选使用 [[买入卡模板]] 预填：

- 入场触发条件（价格 + 成交量）
- 初始止损和目标
- 股数（按风险预算公式计算）
- **不交易条件**（明确写出今日什么情况下不做）

### Step 7 · 检查已有仓位保护位（5 分钟）

对每笔持仓更新 [[持仓卡模板]]：

- [ ] 最新止损位是否需要上移
- [ ] 10 日/20 日退出线
- [ ] 逻辑状态：增强 / 不变 / 削弱 / 证伪
- [ ] 下一动作：持有 / 加仓 / 减仓 / 退出
- [ ] 账户热度是否超限

## 二、盘中纪律

> 时间：09:30—15:00

### 核心原则

```text
只执行计划内交易 · 不因情绪改变计划 · 新热点先观察
```

### 允许的动作

- 执行盘前写入的买入/卖出计划
- 触发止损或退出线时按计划执行
- 记录跳空、涨停、滑点等异常
- 硬公告出现时先核验原文，再决定是否调整

### 禁止的动作

| 禁止行为 | 替代动作 |
|---|---|
| 不因拉升临时提高买入价 | 等待回调或放弃 |
| 不因亏损临时扩大止损 | 按原计划止损 |
| 新热点直接重仓 | 30 分钟冷却 + 写入观察池 |
| 因上一笔盈亏改变下一笔仓位 | 按公式计算，不因情绪调整 |
| 无计划临时下单 | 写入观察，下一交易日再评估 |

### 30 分钟冷却规则

任何盘中临时发现的热点，必须先写下：

1. 信息来源
2. 催化事实
3. 失效条件
4. 止损价
5. 计划仓位

等待至少 30 分钟，仍满足全部规则才允许小仓（≤ 0.25% 风险）。

### 盘中记录

异常情况即时记录（盘后整理）：

- 时间 · 事件 · 是否按计划 · 偏差原因

## 三、盘后 1 小时流程

> 时间：15:30—16:30

### Step 1 · 保存截图（10 分钟）

- [ ] 持仓个股日线图
- [ ] 关键分时图（如有交易）
- [ ] 板块强度排名
- [ ] 大盘指数日 K 线

保存至 Obsidian 附件或本地目录，在日志中链接。

### Step 2 · 记录计划与实际差异（10 分钟）

| 计划动作 | 实际动作 | 偏差 | 原因 |
|---|---|---|---|
| | | | |

### Step 3 · 计算盈亏 R（10 分钟）

- 浮动盈亏 R = 浮动金额 ÷ 单笔风险预算 R
- 已平仓交易：填写 [[复盘卡模板]]
- 更新账户净值和回撤状态

### Step 4 · 标记违规（5 分钟）

对照盘前计划，标记：

- [ ] 追价 · [ ] 扩止损 · [ ] 超仓 · [ ] 无计划交易 · [ ] 情绪下单 · [ ] 过早止盈

### Step 5 · 更新产业数据库（15 分钟）

- 持仓公司新公告 → 更新证据链
- 行业关键数据变化 → 更新 [[行业选择标准]] 评分
- 新发现的产业线索 → 加入 B 级研究池

### Step 6 · 制定明日持仓方案（10 分钟）

对每笔持仓明确：

- 明日止损位
- 触发加仓/减仓/退出的条件
- 不操作的条件

写入 [[持仓卡模板]]，保存至 `每日复盘/` 目录。

---

## 四、周末深度研究

> 时间：周六或周日，2—3 小时

### 4.1 周报编写（45 分钟）

使用 [[周报模板]] 完成：

- 本周市场 A/B/C/D 状态及变化
- 各策略盈亏 R 汇总
- 最大错误与最佳执行
- FOMO/扛亏/过早止盈检查
- 下周总仓位和风险预算
- 重点产业证据链更新

保存至 `每周复盘/` 目录。

### 4.2 深度产业研究（60 分钟）

每周至少深入一个产业：

1. 选择能力圈内一个产业（创新药 / AI 算力 / 半导体等）
2. 更新产业链图谱和上中下游公司
3. 追踪 3—5 家核心公司的最新公告和财报
4. 评估产业阶段：导入 / 成长 / 成熟 / 过剩 / 出清
5. 更新 A/B/C 股票池

### 4.3 更新股票池（30 分钟）

| 池级 | 动作 |
|---|---|
| **A 级（可交易）** | 检查是否仍满足入池条件，移除证伪标的 |
| **B 级（研究）** | 新证据是否足以升级至 A 级 |
| **C 级（观察）** | 清理纯概念、无事实支撑的标的 |

### 4.4 一笔完整复盘（30 分钟）

从本周交易中选一笔（ preferably 最大错误 or 最佳执行）：

- 完整填写 [[复盘卡模板]]
- 分析能力因素 vs 运气因素
- 确定唯一最重要改进
- 判断是否影响系统规则（样本不足时不修改）

## 五、职业投资者的日常信息源

### 5.1 宏观与产业政策

| 来源 | 用途 | 频率 |
|---|---|---|
| 国务院 / 发改委 / 工信部官网 | 产业政策、五年规划 | 每周 |
| 央行 / 统计局 | 流动性、经济数据 | 数据发布日 |
| 新华社 / 人民日报 | 政策风向 | 每日浏览 |
| Wind / 同花顺宏观频道 | 数据汇总 | 每日 |
| 券商宏观策略报告 | 框架参考（不盲信） | 每周 |

### 5.2 上市公司公告

| 来源 | 用途 |
|---|---|
| [巨潮资讯网](http://www.cninfo.com.cn) | 法定披露，一手公告 |
| 上交所 / 深交所官网 | 监管信息、问询函 |
| 公司投资者关系页面 | 路演、纪要 |
| AI 公告摘要助手 | 自动提取关键数字和变化 |

**必看公告类型**：业绩预告 · 重大合同 · 股权激励 · 增减持 · 并购重组 · 监管问询

### 5.3 券商研报

| 来源 | 使用原则 |
|---|---|
| Wind 研报库 | 获取行业框架和数据 |
| 慧博 / 萝卜投研 | 免费研报聚合 |
| 各券商公众号 | 跟踪能力圈行业 |

> 研报用于补充信息，不用于替代独立判断。重点关注：行业数据、竞争格局、盈利预测假设。

### 5.4 行业专家与企业家信息

| 来源 | 跟踪方式 |
|---|---|
| 行业峰会 / 论坛 | 录屏 + 纪要 |
| 上市公司业绩说明会 | 巨潮资讯 / 上证 e 互动 |
| 产业媒体（如医药魔方、芯智讯） | RSS / 公众号 |
| 专家访谈 / 播客 | 提取可验证事实 |
| 上下游公司公告 | 交叉验证行业景气 |

### 5.5 产业数据库维护

**维护原则**：只记录可验证事实，不记录传闻和预测。

| 数据类型 | 存储位置 | 更新频率 |
|---|---|---|
| 公司财务数据 | Obsidian 笔记 / SQLite | 季报后 |
| 产业关键指标 | 产业研究笔记 | 月度 |
| 政策时间线 | 政策追踪笔记 | 事件驱动 |
| 竞争格局 | 公司分析笔记 | 季度 |
| 估值区间 | 买入卡 / 持仓卡 | 交易时 |

**数据库结构建议**：

```text
【2】产业研究/ → 产业链图谱 + 行业数据
【3】企业分析/ → 个股深度 + 财务跟踪
【10】实盘记录/ → 交易执行 + 复盘
【11】统一体系/ → 规则 + 标准 + 工作流
```
