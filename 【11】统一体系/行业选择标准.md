# 行业选择标准评分卡

> **版本**：V5.0 统一版  
> **用途**：在八层决策系统的第 2—6 层提供统一、可审计的量化筛选标准  
> **原则**：任一评分卡单项不达标不自动否决，但综合评分与一票否决清单共同决定最终动作  
> **关联文档**：[[投资体系_V5.0]]

---

# 一、评分体系总览

本评分卡整合 3M 系统四层评分（产业 30 + 公司 25 + 交易结构 15 = **70 分**）、V4.0 凸性与赔率评分（**80 分**）、金融怪杰 100 分法、系统型投资四维框架，以及各版本一票否决项。

## 1.1 使用流程

```text
Step 1：一票否决清单 → 任一命中则停止
Step 2：产业评分（30分）→ 低于18分不主动重仓
Step 3：公司评分（25分）→ 低于15分不建仓
Step 4：交易结构评分（15分）→ 低于9分只能观察
Step 5：凸性与赔率评分（80分）→ 决定仓位级别
Step 6：脆弱性审计 → 发现致命项则降级或放弃
Step 7：综合评分与决策标准 → 确定动作
```

## 1.2 评分与动作速查

| 综合层级 | 条件概要 | 建议动作 |
|---|---|---|
| **A 级** | 无否决项；产业 ≥22；公司 ≥20；交易 ≥12；凸性 ≥80 | 标准建仓，按账户类型取上限 |
| **B 级** | 无否决项；产业 ≥18；公司 ≥15；交易 ≥9；凸性 65—79 | 小仓试错或预埋，验证后加仓 |
| **C 级** | 产业 15—17 或凸性 50—64 | 只做研究，不交易 |
| **D 级** | 产业 <15 或凸性 <50 或脆弱性致命 | 放弃 |

# 二、产业评分（30 分制）

> 来源：3M 系统第二层 + 系统型投资行业周期框架 + 金融怪杰产业趋势维度

**用途**：判断行业是否值得投入研究资源和账户配额。  
**阈值**：低于 **18 分**不主动重仓；**22 分以上**为 A 级产业。

| 维度 | 分值 | 评分标准 |
|---|---:|---|
| **国家战略/政策确定性** | 0—6 | 0—2：无政策支持或政策方向不明；3—4：有方向性支持但落地不确定；5—6：五年规划/支付/准入等硬政策明确且可跟踪 |
| **产业景气和市场空间** | 0—6 | 0—2：需求萎缩或空间受限；3—4：平稳或结构性增长；5—6：渗透率快速提升或 TAM 大幅扩张 |
| **边际变化与预期差** | 0—6 | 0—2：无新变化或已被充分定价；3—4：有变化但影响有限；5—6：关键变量出现拐点且市场尚未充分反应 |
| **板块资金持续性** | 0—6 | 0—2：资金流出或一日游；3—4：间歇性活跃；5—6：成交额持续放大、相对强度居前、龙头有梯队 |
| **估值与拥挤度** | 0—6 | 0—2：估值透支且交易极度拥挤；3—4：合理或略贵；5—6：估值有安全边际或拥挤度低 |

### 产业评分补充检查（不计分，但必须回答）

- 需求是结构性还是周期性？
- 行业处于导入、成长、成熟、过剩还是出清？
- 供给是否容易扩张？
- 价值链利润向哪里迁移？
- 行业冲击会淘汰弱者还是损害所有参与者？

### 重点产业能力圈参考

| 产业 | 关键跟踪变量 |
|---|---|
| 创新药 | 临床数据、审批、医保、BD 授权、现金消耗 |
| AI 算力 | 芯片、服务器、光模块、液冷、IDC、电力传导 |
| 半导体 | 设备、材料、设计、制造、封测与周期 |
| 商业航天 | 卫星制造、火箭、地面设备、运营与订单兑现 |
| 周期资源 | 油气、黄金、铜、煤炭、化工品供需与价格周期 |

# 三、公司评分（25 分制）

> 来源：3M 系统第三层 + V4.0 公司质量审计 + 思考快与慢六道门

**用途**：判断具体公司是否具备持有价值。  
**阈值**：低于 **15 分**不建仓；**20 分以上**为 A 级公司。

| 维度 | 分值 | 评分标准 |
|---|---:|---|
| **产品/技术壁垒** | 0—5 | 0—1：无壁垒或易被替代；2—3：有一定差异化；4—5：技术/品牌/网络效应/转换成本形成清晰壁垒 |
| **商业模式与盈利路径** | 0—5 | 0—1：无法解释如何赚钱；2—3：路径清晰但尚未稳定兑现；4—5：收入模式清晰、单位经济改善、盈利路径可验证 |
| **管理层与资本配置** | 0—5 | 0—1：治理重大疑点或乱投资；2—3：一般；4—5：资本配置理性、股东回报意识强、诚信记录良好 |
| **财务质量与现金流** | 0—5 | 0—1：现金流差、高杠杆或利润质量差；2—3：基本健康；4—5：经营现金流持续、负债可控、应收/库存合理 |
| **估值情景与安全边际** | 0—5 | 0—1：价格已透支乐观情景；2—3：合理；4—5：保守情景下有明确安全边际，概率加权价值高于现价 |

### 创新药额外检查（任一严重缺陷扣 2—5 分）

| 检查项 | 合格标准 |
|---|---|
| 临床价值 | 主要终点有临床意义，非仅统计显著 |
| 竞争格局 | 差异化清晰，非红海 Me-too |
| 适应症空间 | 患者人群和支付能力可估算 |
| 商业化能力 | 有销售团队或合作伙伴，非纯研发故事 |
| 现金储备 | 跑道覆盖下一关键里程碑 + 6 个月缓冲 |
| BD 条款 | 首付款/里程碑/分成区分确定部分与或有部分 |

# 四、交易结构评分（15 分制）

> 来源：3M 系统第四层 + 海龟突破系统 + 三重滤网

**用途**：判断当前是否是可承担风险的入场点。  
**阈值**：低于 **9 分**只能观察；**12 分以上**可配合 A 级基本面标准建仓。

| 维度 | 分值 | 评分标准 |
|---|---:|---|
| **周线趋势** | 0—3 | 0：周线下降趋势；1：横盘；2：趋势改善中；3：位于 20 周均线上方且趋势向上 |
| **日线结构** | 0—3 | 0：无结构或加速远离均线；1：弱势；2：回调至均线/平台；3：突破/二次确认结构完整 |
| **成交量与承接** | 0—3 | 0：缩量下跌或无承接；1：一般；2：温和放量；3：突破放量或回调缩量，筹码稳定 |
| **板块联动** | 0—3 | 0：个股独涨或板块退潮；1：弱联动；2：板块同步；3：板块共振、龙头梯队完整 |
| **风险收益比** | 0—3 | 0：<1.5:1；1：1.5—2:1；2：2—3:1；3：≥3:1 且止损位明确 |

### 三重滤网快速检查

**第一滤网（周线）**——至少满足三项：

- [ ] 指数位于 20 周均线之上或周线趋势改善
- [ ] 目标板块相对强度进入前 20%
- [ ] 周线 MACD 柱改善
- [ ] 板块成交额持续放大
- [ ] 核心催化不是一次性小作文

**第二滤网（日线）**——优先结构：

- [ ] 上升趋势回调至 10/20 日均线
- [ ] 平台突破且次日不高开低走
- [ ] 事件后二次确认再突破

**禁止入场**：

- [ ] 连续加速后远离均线追入
- [ ] 板块退潮中的个股独涨
- [ ] 重大利好高开低走后盲目抄底

# 五、凸性与赔率评分（80 分制）

> 来源：V4.0 第六层 + 思考快与慢认知风险扣分 + 金融怪杰预期差维度

**用途**：判断机会的赔率和反脆弱性，决定仓位级别。  
**阈值**：**80 分以上**正式候选；**65—79 分**小仓观察；**50—64 分**只研究；**50 分以下**放弃。

| 项目 | 分值 | 评分标准 |
|---|---:|---|
| **最大损失是否明确且可控** | 0—20 | 0—5：无法估算下行；6—10：下行模糊；11—15：有止损但跳空风险高；16—20：压力情景损失可量化且可承受 |
| **企业是否有足够现金和时间** | 0—15 | 0—3：融资依赖高、跑道不足；4—8：勉强覆盖近期；9—12：跑道充足；13—15：现金充裕、无短期生存压力 |
| **上行是否存在两条以上独立路径** | 0—15 | 0—3：单一路径；4—8：1—2 条路径；9—12：2 条独立路径；13—15：多条独立上行且互不依赖 |
| **当前价格是否有安全边际** | 0—15 | 0—3：透支乐观情景；4—8：合理定价；9—12：保守情景有空间；13—15：压力情景下仍有一定保护 |
| **催化是否可验证** | 0—10 | 0—2：纯概念；3—5：有时间但不确定；6—8：有明确时间窗口和验证指标；9—10：硬催化且可跟踪 |
| **成功后收益是否可扩展** | 0—10 | 0—2：一次性事件；3—5：有限空间；6—8：可中期扩展；9—10：成功后能形成复利或平台价值 |
| **失败是否能快速识别和退出** | 0—10 | 0—2：无法证伪；3—5：证伪慢；6—8：有明确指标；9—10：硬逻辑失效点清晰、时间窗口明确 |
| **与现有组合相关性是否低** | 0—5 | 0—1：高度相关；2—3：部分相关；4—5：独立因子、降低组合集中度 |

### 认知风险扣分（从总分中扣除）

| 风险 | 扣分 |
|---|---:|
| 单一生动新闻驱动 | −5 至 −10 |
| 估值依赖一个乐观情景 | −5 至 −15 |
| 缺乏基准概率 | −5 |
| 信息高度同源 | −5 |
| 已有重仓并强烈希望上涨 | −5 |
| 买入理由含成本、回本、洗盘 | −10 |
| 合同/审批/里程碑仍有重大条件 | −3 至 −10 |
| 流动性差、涨跌停或跳空风险高 | −5 至 −10 |

> 认知风险扣分不能被"我非常有信心"抵消。最终得分 = 基础分 − 认知风险扣分。

# 六、脆弱性审计清单

> 来源：V4.0 第三层 + 系统型投资否决门 + 思考快与慢生存门

**用途**：识别可能导致永久损失的结构性风险。每项标注 **[致命]** 或 **[警告]**。

## 6.1 财务脆弱性

| 检查项 | 级别 | 发现则 |
|---|---|---|
| 净负债/短债过高，经营现金流无法覆盖 | 致命 | 放弃或 ≤ 实验仓 |
| 经营现金流长期低于净利润 | 警告 | 降级，最高小仓 |
| 应收/库存/商誉异常增长 | 警告 | 深入核查，不加仓 |
| 依赖一次融资或一次订单续命 | 致命 | 放弃 |
| 大额解禁在即且承接不足 | 警告 | 不建仓或极小仓 |

## 6.2 经营脆弱性

| 检查项 | 级别 | 发现则 |
|---|---|---|
| 客户/供应商/产品/地域高度集中 | 警告 | 降低仓位上限 |
| 固定成本高、产能利用率低 | 警告 | 周期股特别审查 |
| 核心产品单一且面临二元风险 | 警告 | 创新药按专用规则限仓 |
| 重大诉讼、合规或治理问题 | 致命 | 放弃 |

## 6.3 系统脆弱性（系统型投资否决门）

即使总分较高，出现以下任一情况不得重仓：

| 检查项 | 说明 |
|---|---|
| 说不清核心因果链 | 逻辑不可审计 |
| 只有增强回路，没有调节回路 | 过度乐观 |
| 无法识别增长极限 | 估值无锚 |
| 关键结果依赖单一二元事件 | 仓位必须 ≤ 事件上限 |
| 时间延迟与持有周期不匹配 | 资金效率风险 |
| 证伪条件不明确 | 无法退出 |
| 估值已隐含极高成功率 | 赔率不足 |
| 组合相关性过高 | 伪分散 |
| 流动性不足 | 无法按计划退出 |

## 6.4 脆弱性审计结论

| 结论 | 动作 |
|---|---|
| 无致命项，警告 ≤ 1 项 | 正常执行评分动作 |
| 警告 2—3 项 | 仓位上限减半 |
| 任一致命项 | 放弃，或仅限实验仓 ≤ 0.5% |

# 七、一票否决清单

> 来源：海龟版 4.3 节 + 3M 排除条件 + 金融怪杰一票否决 + 各版本禁止事项汇总

**以下任一情况存在，原则上不得进入趋势交易池或建立正式仓位**（实验仓 ≤ 0.25% 的验证性研究除外）：

## 7.1 硬性否决（财务与合规）

- [ ] 重大财务造假或审计疑点
- [ ] 退市、ST、持续经营重大不确定性
- [ ] 管理层诚信存在严重问题
- [ ] 重大治理、质押或关联交易风险

## 7.2 流动性与执行否决

- [ ] 流动性无法支持计划仓位（日均成交额不足以在 3 日内减仓 50%）
- [ ] 连续一字板，无法建立止损
- [ ] 即将发生无法评估的大额解禁
- [ ] 需要借贷或融资才能达到期望仓位

## 7.3 信息与逻辑否决

- [ ] 主要逻辑仅来自未核实的小作文
- [ ] 交易逻辑无法用三句话说清
- [ ] 无法写出三条明确失败信号
- [ ] 纯小作文，无可核实信息
- [ ] 预期收益/风险比不足 1.5:1

## 7.4 事件与仓位否决

- [ ] 核心产品临床或审批二元风险，且仓位无法覆盖跳空
- [ ] 重大临床/审批结果前却无法承受跳空
- [ ] 单一二元事件决定企业生存且仓位计划过大
- [ ] 大额合同尚未签署却已按全部收入估值

## 7.5 行为与状态否决

- [ ] 自己处于报复性交易或严重焦虑状态
- [ ] 为回本而明显提高仓位
- [ ] 连续亏损后想快速翻本
- [ ] 因错过上涨产生追涨焦虑
- [ ] 买入理由含"这次不一样""不会再给机会""主力洗盘"
- [ ] 需要通过补仓避免确认亏损

## 7.6 投资委员会否决权（快速检查）

```text
[ ] 是否依赖借贷或杠杆？
[ ] 是否因为害怕错过而买入？
[ ] 是否无法写出悲观情景？
[ ] 是否单票或行业超限？
[ ] 是否只凭技术图形或小作文？
[ ] 是否把未触发里程碑当作确定收入？
[ ] 是否在公告后大涨时临时改变估值？
[ ] 是否没有明确的逻辑失效条件？
[ ] 是否会因本次亏损影响生活和职业计划？
```

**任一勾选为"是" → 自动否决。**

# 八、综合评分与决策标准

## 8.1 综合评分矩阵

将四层评分映射到统一决策矩阵：

| 指标 | 权重参考 | A 级 | B 级 | C 级 | D 级 |
|---|---:|---:|---:|---:|---:|
| 产业评分（/30） | 25% | ≥22 | 18—21 | 15—17 | <15 |
| 公司评分（/25） | 25% | ≥20 | 15—19 | 12—14 | <12 |
| 交易结构（/15） | 15% | ≥12 | 9—11 | 6—8 | <6 |
| 凸性赔率（/80） | 35% | ≥80 | 65—79 | 50—64 | <50 |

> 凸性赔率权重最高，因为它直接决定"是否值得承担不确定性"。

## 8.2 决策动作表

| 综合等级 | 前置条件 | 账户 | 初始仓位 | 验证后上限 | 单笔风险 |
|---|---|---|---:|---:|---:|
| **A 级** | 无否决；无致命脆弱性 | 按类型分配 | 按类型标准 | 按类型上限 | 标准风险率 |
| **B 级** | 无否决；警告 ≤ 1 | 产业/事件 | 类型的 50% | 类型的 70% | 标准 × 0.7 |
| **C 级** | — | — | 不交易 | — | — |
| **D 级** | — | — | 放弃 | — | — |

## 8.3 特殊类型调整

| 类型 | A 级额外条件 | 上限调整 |
|---|---|---|
| 创新药 | 完成 SOTP；现金跑道充足；完成创新药额外检查 | 最高 6%，二元事件前 × 跳空折扣 |
| 事件驱动 | 硬催化 ≥ 4 级来源；板块共振；事件模型得分高 | 最高 4%，只在事件账户 |
| 核心复利 | S2-A 55 日突破或估值修复；Slow 系统确认 | 最高 10% |
| 周期资源 | 识别周期位置，非景气顶点利润估值 | 最高 8%，注意宏观因子合并 |
